Button

工具栏上的带字按钮，以及文件树角落的实心 Search。没有主色按钮，也没有危险按钮。

示例

用法

<Button variant="toolbar">新建</Button>
<Button variant="toolbar" aria-expanded>查看</Button>
<Button variant="solid" size="s">Search</Button>

API

Prop类型默认说明
variant"toolbar" | "quiet" | "solid"toolbar没有 primary / danger
size"s" | "m"m高 24 / 32
iconReactNode—可选，放在文字前
…buttonButtonHTMLAttributestype=button其余交给原生 button

设计说明

对照文件管理工具栏和文件树右下角的 Search。

  • 匹配：工具栏按钮是浅灰底，不是导航那种浅蓝。实心 Search 是中性深灰字白。
  • 匹配：圆角用印出的 8vp。字号 13px 是从窗口控件推断的，菜单才用 Body_L。
  • 待确认：主色 / 危险按钮稿上没有，不补。
