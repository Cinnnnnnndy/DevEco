## 看到了，但没有当成 DevEco 控件

| 帧 | 原因 |
| --- | --- |
| NewUI `601ef849…`、`0dfc102f…`、`e56391e6…` | 设计工具自己的菜单和检查器 |
| NewUI `797fe108…` | 设计工具的阴影编辑器。其中的 X0 Y3 模糊 12、`#1B1F26` 18% 不写入 token |
| NewUI `25b80b2a…`、`f4b69042…` | 组件属性检查器，不是控件渲染 |
| 基础范式 `2895d432…` | Fleet 竞品 |
| 基础范式 `16175e7c…`、`7762ab51…` 等 | 访谈照片 |
| PC 组件库多数单帧 | 应用图标、墙纸、封面卡 |
| TUI 单帧 | 标志，或一段终端里的回顾文字。总览缩略图上的控件表分辨率不够 |
| LOGO 单帧 | 有三角形标志和 DevEco Studio 锁版，没有矢量规格 |
