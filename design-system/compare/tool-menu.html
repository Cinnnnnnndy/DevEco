组件文档 · button

Button

支持主按钮（Primary）、次按钮（Secondary）、告警按钮（Danger/Alarm）、工具栏按钮（Toolbar）与安静按钮（Quiet）。鸿蒙原生端高 34vp、圆角 8vp（次按钮为 10% 叠加底配品牌蓝字 #0A59F7/#5291FF，告警按钮为 10% 叠加底配红字 #E84026/#D94838）；PC/Mac 端高 28px（紧凑 24px）、圆角 4px。

示例

用法

import { Button } from "./button";

<Button variant="primary">Confirm</Button>
<Button variant="secondary">Cancel</Button>
<Button variant="danger">Alarm</Button>
<Button variant="toolbar" icon={<IconPlus />}>Create Files</Button>

API

Prop / 组件类型默认说明
variant"primary" | "secondary" | "danger" | "toolbar" | "quiet" | "solid""secondary"对应 Pixso 1-主按钮 / 2-次按钮 / 3-告警按钮 / 4-图标文字按钮
size"s" | "m""m"鸿蒙端 28vp / 34vp；PC/Mac 端 24px / 28px
iconReactNode—可选前置图标
…buttonButtonHTMLAttributestype="button"原生 button 属性

Pixso 源文件对齐说明

  • 鸿蒙原生端（鸿蒙IDE_v1.1.0_PC端组件库.pix · 4.1按钮）：高 34vp，圆角 8vp，字号 16vp。1-主按钮浅色 #0A59F7（悬停 #236AF8）、深色 #317AF7（悬停 #2C6EDE）、置灰 40%；2-次按钮采用 10% 叠加底 + 品牌蓝文字；3-告警按钮采用 10% 叠加底 + 告警红文字（#E84026 / #D94838）。
  • PC/Mac 当代桌面端（【NewUI】鸿蒙IDE-当代.pix · Button 页）：Default 高 28px、Slim 高 24px，圆角 4px，字号 13px。Primary 为 #3574F0 实心蓝，Secondary 为 1px 描边（#C9CCD6 / #4E5157），Danger 为 #DB3B4B / #DB5C5C。
