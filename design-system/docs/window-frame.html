PC / Mac

WindowFrame

鸿蒙电脑窗口。标题栏约是浅灰，右侧是还原、最小化、关闭。

示例

主页

窗口内容

用法

import { WindowFrame } from "./window-frame";

<WindowFrame title="主页">
  {/* 内容 */}
</WindowFrame>

API

Prop类型默认说明
titleReactNode必填标题
markReactNode色块不是 Logo
controlsReactNode还原/最小化/关闭装饰，不可聚焦

设计说明

标题栏取样 #E5E5E5。窗口外圆角 16px 是按帧上的弧度推断的，唯一印出的圆角仍是菜单的 8vp。左上色块只是占位，Logo 矢量没有。
