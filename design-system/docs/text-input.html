鸿蒙 4.4单行文本输入 + 4.6报错tips & PC/Mac Input

TextInput

单行文本输入与表单校验反馈。支持默认、激活、禁用与报错态（配 4.6报错tips 警示条）。

示例

set-01
set-02
报错内容显示：模块名不能包含特殊字符（4.6报错tips）

用法

import { TextInput } from "./text-input";

<TextInput label="工程名" defaultValue="MyApplication" />
<TextInput
  label="模块名"
  state="error"
  defaultValue="entry@invalid"
  errorTip="报错内容显示：模块名不能包含特殊字符"
/>

API

Prop / 组件类型默认说明
labelReactNode—字段标签
state"default" | "active" | "error""default"报错态使用 #CF3922 (浅) / #D94838 (深) 描边
errorTipReactNode—4.6报错tips（高 28vp，r=4vp，浅色 #FBE0DC / 深色 #4E3231）
inlinebooleanfalse是否采用水平表单布局
