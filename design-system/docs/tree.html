Tree

文件树。展开的文件夹和选中的文件是中性灰，不是侧栏的浅蓝。

示例

  • › 6、模块流程 (17)
    • › Search (6)
      • ›2.find in flies视觉样式
      • ›3.文档内搜索视觉样式

用法

import { Tree, TreeItem } from "./tree";

<Tree>
  <TreeItem label="6、模块流程" count="(17)" defaultOpen>
    <TreeItem label="Search" count="(6)" selected />
    <TreeItem label="1. 搜索视觉样式 light" />
  </TreeItem>
</Tree>

API

Prop类型默认说明
labelReactNode必填行标题
countReactNode—右侧计数
selectedbooleanfalse中性灰选中
defaultOpenboolean—有子节点时展开
childrenReactNode—子行

设计说明

上一轮误用了侧栏的浅蓝。文件树帧里选中行取样是 #E6E6E6，悬停 #ECECEC。已改，并标为从预览图推断。
