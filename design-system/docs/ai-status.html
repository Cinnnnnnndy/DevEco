AiStatus

智能状态胶囊。来自 intui-kit 的 AI 视觉规范，Pixso 预览没有这套色。智能色只表示「这是 AI 在做」，不拿去改菜单、树和侧栏。

示例

import { AiStatus } from "./ai-status";

Prop类型默认说明

设计说明

来源 data-de-source="intui-kit"。色值来自 kit 的智能色，不是 Pixso 印出值。界面字体用 HarmonyOS Sans SC，PingFang SC 只作回退。不把这套紫当作 Pixso 侧栏或主按钮。
