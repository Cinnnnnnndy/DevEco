AiStatus

CodeGenie / Agent 进行态状态胶囊（理解中、生成中、在等你、完成、报错）与行内续写幽灵字。

示例

理解中 生成中 在等你确认 已完成 已停止

用法

import { AiStatus } from "./ai-status";

<AiStatus state="waiting">在等你确认</AiStatus>

API

Prop / 组件类型默认说明
state"idle" | "thinking" | "generating" | "waiting" | "done" | "error""idle"AI 状态机
childrenReactNode必填状态文案
