鸿蒙 6.2Tooltip & PC/Mac Tooltip

Tooltip

悬停或聚焦控件时显示的轻量化气泡说明（高 28vp，圆角 4vp，浅色 #FFFFFF / 深色 #4D4D4D + 双描边 + y10 阴影）。

示例

用法

import { Tooltip } from "./tooltip";

<Tooltip content="构建并运行当前模块 (⇧F10)">
  <Button variant="secondary">Run Entry</Button>
</Tooltip>

API

Prop / 组件类型默认说明
contentstring必填提示文案
childrenReactNode必填触发器元素

Pixso 源文件对齐说明

  • 鸿蒙原生端（6.2Tooltip 247×28 r=4）：浅色底 #FFFFFF（外描边 #000 10%、内描边 #FFF 20%），深色底 #4D4D4D（外描边 #000 40%、内描边 #FFF 20%）。
