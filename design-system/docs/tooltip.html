Tooltip

悬停「预览」时出现的说明。稿上的句子是「显示或隐藏预览窗格。」

示例

用法

import { Tooltip } from "./tooltip";
import { Button } from "./button";

<Tooltip content="显示或隐藏预览窗格。">
  <Button variant="toolbar">预览</Button>
</Tooltip>

API

Prop类型默认说明
contentstring必填说明文字
childrenReactNode必填触发器

设计说明

浮层用未具名的 y10 阴影。标注没写这个阴影属于提示还是别的浮层，所以这是推断，写在 token 注释里。
