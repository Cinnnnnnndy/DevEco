PC / Mac · intui-kit

MessageBar

每条消息下面那一排：复制、重新回答、时间。来自 intui-kit 的消息操作栏。栏上不用智能色。你发的消息悬停才出现操作。

示例

把结果写进 Index.ets。

20 分钟前
帮我看一下这个页面。
3 分钟前

用法

import { MessageBar, MessageBarButton } from "./message-bar";

<MessageBar time="20 分钟前">
  <MessageBarButton>复制</MessageBarButton>
  <MessageBarButton>重新回答</MessageBarButton>
</MessageBar>

API

Prop类型默认说明
timestring—相对时间
editedbooleanfalse时间后加「已编辑」
donebooleanfalse按钮：已复制，变绿

设计说明

来自 intui-kit，Pixso 没有这排操作。成功绿用 kit 的 success 色。不把它当成 Pixso 主按钮。
