PC / Mac

Menu

普通菜单。备忘录里的「打印」是浅灰当前项，「锁定图文布局」是不可用项。

示例

用法

import { Menu, MenuItem, MenuSeparator } from "./menu";

<Menu>
  <MenuItem>启用备忘锁</MenuItem>
  <MenuItem disabled>锁定图文布局</MenuItem>
  <MenuItem current>打印</MenuItem>
  <MenuSeparator />
  <MenuItem>删除</MenuItem>
</Menu>

API

Prop类型默认说明
iconReactNode—MenuItem 左侧
shortcutstring—右侧快捷键
currentbooleanfalse当前项
disabledbooleanfalse不可用，颜色用 text-tertiary

设计说明

底板圆角 8vp、阴影 defaultShadowS_PC（x0 y0 16vp #33000000）、双描边，都按标注。

  • 匹配：浅色当前项是灰 #E2E2E2，不是侧栏那种浅蓝。这一轮从备忘录帧改过来的。
  • 字重按标注 Body_L Medium。备忘录截图观感更接近常规字重，仍跟标注，等 Pixso 变量核对。
  • 待确认：未具名的 y10 阴影没有用在这层菜单上。
