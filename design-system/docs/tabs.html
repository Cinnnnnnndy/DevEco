PC / Mac

Tabs

文本编辑器的文档页签。选中页是白底，条本身是浅灰。

示例

用法

import { Tabs, Tab } from "./tabs";

<Tabs>
  <Tab selected onClose={() => {}}>文档 1</Tab>
  <Tab>文档 2</Tab>
</Tabs>

API

Prop类型默认说明
selectedbooleanfalse当前页签
onClose() => void—有关闭钮
closeLabelstring关闭关闭钮的名字

设计说明

这一轮去掉了选中页底下的黑线。稿上是浅灰条 #F1F5F8 托着白底页签。圆角只加在页签上沿，数值是推断。
