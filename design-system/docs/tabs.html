鸿蒙 7.代码区页签 & PC/Mac Editor Tabs

Tabs

代码编辑器文件页签条。鸿蒙端高 28vp、圆角 6vp、选中铺 10% 叠加底；PC/Mac 端高 40px、底部 3px #3574F0 激活指示条。

示例

用法

import { Tabs, Tab } from "./tabs";

<Tabs>
  <Tab selected onClose={() => {}}>EntryAbility.ets</Tab>
  <Tab onClose={() => {}}>BadgeCardComponent.cpp</Tab>
</Tabs>

API

Prop / 组件类型默认说明
selectedbooleanfalse是否为当前打开页签
onClose() => void—关闭按钮回调
closeLabelstring"关闭"无障碍标签
