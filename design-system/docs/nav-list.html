PC / Mac

NavList

文件管理左侧。当前项是浅蓝底，图标保持自己的颜色，不统一染蓝。

示例

快速访问

用法

import { NavList, NavLabel, NavItem } from "./nav-list";

<NavList>
  <NavItem current>主页</NavItem>
  <NavLabel>快速访问</NavLabel>
  <NavItem>桌面</NavItem>
</NavList>

API

Prop类型默认说明
currentbooleanfalsearia-current=page，浅蓝底
iconReactNode—调用方自己上色
labelstring导航NavList 的 aria-label

设计说明

选中底取样 #E7EFFC 到 #E8EEFA。上一轮把所有图标强制成 #4890F0，和稿不符：主页图标是深色，文档、下载、图片各有自己的颜色。已去掉统一染色。
