PC / Mac

IconButton

只有图标的按钮。文件管理工具栏里的剪切、复制，以及鸿蒙图标条，都用它。

示例

用法

import { IconButton } from "./icon-button";
import { IconMore } from "../icons";

<IconButton label="更多" icon={<IconMore />} />
<IconButton label="运行" icon={<IconPlay />} pressed />

API

Prop类型默认说明
labelstring必填写入 aria-label
iconReactNode必填16px 图标
size"s" | "m"m正方形
pressedboolean—当前项，aria-pressed

设计说明

图标条和工具栏的纯图标按钮默认没有底色，按下或当前项才铺一层。

  • 匹配：文件管理里一排工具图标是线框，没有各自的色块。
  • 待确认：整套图标字体没有矢量名录，这里只用功能线框，不假装是稿里的图标库。
