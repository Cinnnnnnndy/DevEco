鸿蒙 4.2图标组 / 3.3侧边工具栏 & PC/Mac Action Button

IconButton

纯图标触发器。支持 M（32×32 r=6，用于侧边工具条 ToolStripe 与主工具栏）和 S（24×24 r=4，用于面板标题栏与内联操作）。

示例

用法

import { IconButton } from "./icon-button";

<IconButton label="运行" icon={<IconPlay />} pressed />
<IconButton size="s" label="关闭" icon={<IconClose />} />

API

Prop / 组件类型默认说明
labelstring必填写入 aria-label
iconReactNode必填图标节点（鸿蒙端 20px/24px，PC/Mac 端 16px）
size"s" | "m""m"24×24 (r=4) 或 32×32 (r=6)
pressedbooleanfalse激活/当前项状态（aria-pressed）

Pixso 源文件对齐说明

  • 鸿蒙原生端（4.2图标组 & 3.3侧边工具栏）：图标 20vp、热区 24×24 r=4vp（S），侧边工具栏 32×32 r=6vp（M）。悬停 10% 叠加底，按下 15% 叠加底，激活 40% 品牌蓝（#0A59F7 / #317AF7）。
  • PC/Mac 端：侧边工具条选中态填充 #3574F0 主蓝并反白图标。
