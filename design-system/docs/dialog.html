Pixso 源文件对齐说明

  • ohos_id_color_dialog_bg 已从 PC端组件库 d82f0c5a...png 核实：浅色 #FFFFFF（面板 #F0F2F4/#F1F3F5）、深色 #202224（弹窗底 #2B2E30）、抬升深色 #3C3C3C。
  • Elevation 55（弹窗失焦 FloatShadowS）：0 10px 55px rgba(0,0,30,0.25)（浅）/ rgba(0,0,0,0.30)（深）；Elevation 70（弹窗聚焦 FloatShadowM）：0 10px 70px rgba(0,0,30,0.45)（浅）/ rgba(0,0,0,0.50)（深）。
