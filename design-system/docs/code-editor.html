CodeEditor

带行号排水沟（Gutter）、当前行高亮、右上角语法告警卡片（告警卡片icon）与真实 Pixso 语法高亮色的代码编辑区。

示例

0 告警 · 2 提示
1import UIAbility from '@ohos.app.ability.UIAbility';
2export default class EntryAbility extends UIAbility {
3 private static TAG: string = 'EntryAbility';
4 async onCreate() { // 初始化 RDB 存储 }
5}

用法

import { CodeEditor, CodeLine } from "./code-editor";

<CodeEditor alertBadge=" 0 告警">
  <CodeLine lineNumber={1}><span className="kw">import</span> UIAbility...</CodeLine>
</CodeEditor>

API

Prop / 组件类型默认说明
alertBadgeReactNode—右上角告警状态卡（对应 7.代码区相关 > 告警卡片icon）
lineNumbernumber必填CodeLine 行号
currentbooleanfalse当前光标所在行高亮

Pixso 源文件对齐说明

  • 语法高亮色全部取自 Pixso 共享样式（Editor/Light/*、Editor/Dark/* 与 7.代码区相关：#67AFFF、#40C793、#9A89FF、#E881DB、#F8CD75）。
