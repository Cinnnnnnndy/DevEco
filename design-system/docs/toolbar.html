PC / Mac

Toolbar

窗口标题下的一排操作。带字的是浅灰按钮，纯图标另用 IconButton。

示例

用法

import { Toolbar, ToolbarSeparator, ToolbarSpacer } from "./toolbar";
import { Button } from "./button";

<Toolbar label="文件">
  <Button>新建</Button>
  <ToolbarSeparator />
  <ToolbarSpacer />
  <Button>预览</Button>
</Toolbar>

API

Prop类型默认说明
labelstring工具栏aria-label
childrenReactNode—按钮和分隔

设计说明

「预览」在稿上是浅灰圆角块，取样约 #F0F0F0。工具栏不再借用侧栏选中蓝。
