鸿蒙端

ToolStripe

编辑器一侧的深色图标条。点一项，当前项铺上和菜单相同的石板蓝。

示例

用法

import { ToolStripe } from "./tool-stripe";
import { IconButton } from "../pc-mac/icon-button";

<ToolStripe>
  <IconButton label="运行" icon={<IconPlay />} pressed />
</ToolStripe>

API

Prop类型默认说明
labelstring工具aria-label
childrenReactNode—IconButton

设计说明

条的底色取样自工具条，约 #242428。图标是线框白色。没有把设计工具属性面板上的蓝色开关拿来当条上的控件。
