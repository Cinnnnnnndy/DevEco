鸿蒙 4.5下拉 / 4.8微调器 / 4.9选择项 / Switch & NewUI Selection

Select / Checkbox / Radio / Switch / Segmented

完整涵盖下拉选择框（4.5）、数值微调器（4.8）、复选框与单选框（4.9）、开关（Switch 28×18）与分段控制器（页签/选择器）。

示例

用法

import { SelectField, Checkbox, Radio, Switch, SegmentedControl, SpinnerField } from "./selection";

<SelectField><option>HarmonyOS 6.0</option></SelectField>
<Checkbox label="开启 AI 代码补全" defaultChecked />
<Switch label="LSP 实时检查" defaultChecked />

API

Prop / 组件类型默认说明
SelectFieldlabel, disabled, children—4.5下拉选择（28px 高，r=4px）
Checkbox / Radiolabel, checked, disabled—4.9选择项（鸿蒙端 20×20，PC/Mac 端 16×16）
Switchlabel, checked, disabled—Switch（28×18 r=25，圆点 14×14，激活 #0A59F7/#317AF7）
SegmentedControloptions, value, onChange—页签/选择器（28px 高 r=6px，内嵌 24px r=4px 选中项）

Pixso 源文件对齐说明

  • Switch 直接取自 鸿蒙IDE_v1.1.0_PC端组件库.pix 的 1.图标 > Switch（8 个变体：深色模式 on/off × 开关 on/off × 可用 on/off，尺寸 28×18，滑块 14×14）。
