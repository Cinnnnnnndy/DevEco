鸿蒙端

ToolMenu

Studio 工具菜单。深底，当前项是石板蓝。对外不叫 IntelliJ 或 Int UI。

示例

用法

import { ToolMenu, ToolMenuItem } from "./tool-menu";

<ToolMenu>
  <ToolMenuItem current shortcut="⌘0">提交</ToolMenuItem>
  <ToolMenuItem shortcut="⌘3">查找</ToolMenuItem>
</ToolMenu>

API

Prop类型默认说明
currentbooleanfalse石板蓝当前项
shortcutstring—右侧快捷键
iconReactNode—左侧图标

设计说明

底色取样 #2C2C30，当前项 #2E436E。普通菜单的 Body_L 不用在这里：工具菜单帧上的字更小，本库用 13px、字重 400，标为从预览图推断。快捷键字形以稿为准，Linux 上可能缺 ⌘ 字体。
