鸿蒙 4.3搜索 & PC/Mac Search Field

SearchField

搜索输入框（高 28px，圆角 4px）。支持默认、悬停、激活（聚焦描边）与置灰状态。

示例

用法

import { SearchField } from "./search-field";

<SearchField placeholder="Search..." />

API

Prop / 组件类型默认说明
labelstring"搜索"无障碍读屏标签
iconReactNode搜索图标前置图标
…inputInputHTMLAttributestype="search"透传给原生 input

Pixso 源文件对齐说明

  • 鸿蒙原生端（4.3搜索 400×28 r=4）：默认采用 5% 叠加底（浅色 #000 5%、深色 #FFF 5%）无描边；悬停为 15% 叠加底；激活/输入中增加 1px #0A59F7 / #317AF7 描边；置灰为 5% 底 + 10% 描边。
  • PC/Mac 端（NewUI Search）：白底 / #2B2D30 底 + 1px #C9CCD6 / #4E5157 描边。
