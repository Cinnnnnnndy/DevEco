组件索引

从本地 Pixso 源文件（鸿蒙IDE_v1.1.0_PC端组件库.pix、👉🔥【2.0】基础范式🔥👈.pix、【NewUI】鸿蒙IDE-当代.pix、icon.pix、【TUI】DevEco Code 基础UI规范.pix）直接解码 13 万+ 矢量节点与 5,000+ 共享样式构建。每个组件均支持在 鸿蒙原生端（HDesign 2.0） 与 PC / Mac 当代桌面端（IntelliJ NewUI） 之间切换深色、浅色与浅色高对比主题。

通用核心组件（17）

  • Button — 鸿蒙 4.1按钮 & PC/Mac NewUI Button
  • IconButton — 鸿蒙 4.2图标组 / 3.3侧边工具栏 & PC/Mac Action Button
  • SearchField — 鸿蒙 4.3搜索 & PC/Mac Search Field
  • TextInput — 鸿蒙 4.4单行文本输入 + 4.6报错tips & PC/Mac Input
  • Select / Checkbox / Radio / Switch / Segmented — 鸿蒙 4.5下拉 / 4.8微调器 / 4.9选择项 / Switch & NewUI Selection
  • Dialog / Notification / Banner — 鸿蒙 6.1 dailog / 6.3 notification / 6.6 横幅 & NewUI Dialog
  • Menu — 鸿蒙 6.4/6.5 Menu & PC/Mac Context Menu
  • Tooltip — 鸿蒙 6.2Tooltip & PC/Mac Tooltip
  • Tabs — 鸿蒙 7.代码区页签 & PC/Mac Editor Tabs
  • CodeEditor — 鸿蒙 7.代码区相关 / 1、风格化token-代码区 & NewUI Editor
  • Tree — 鸿蒙 5.3列表(树结构) / 5.4带行号树 & NewUI Tree
  • Toolbar — 鸿蒙 3.6工具栏标题 & PC/Mac Toolbar
  • NavList — 侧栏导航与设置树 (NavList)
  • Chip — 鸿蒙 4.7筛选标签 & PC/Mac Filter Chip
  • Tag — 鸿蒙 4.11标签 & PC/Mac Badge Tag
  • WindowFrame — 鸿蒙 2.布局组件 / 3.1顶部栏 & PC/Mac Main Window
  • StatusBar — 鸿蒙 3.2底部栏 + 3.5 LSP进度条 & PC/Mac Status Bar

AI 与工具窗口组件（4）

  • AiStatus — PC / Mac & 鸿蒙 · 来自 deveco-intui-kit + chat.pix
  • MessageBar — PC / Mac & 鸿蒙 · 来自 deveco-intui-kit + chat.pix
  • ToolMenu — Studio 工具窗口菜单 (icon.pix)
  • ToolStripe — 鸿蒙 3.3侧边工具栏 & PC/Mac Tool Window Bar

整窗模式示例

  • HarmonyIdeWindow（原 FileWindow 路由） — 鸿蒙原生 DevEco Studio 2.0 完整 IDE 工作台（顶栏、毛玻璃 Project 树、代码区、底栏与 LSP 胶囊）
  • StudioToolWindow — PC / Mac 当代桌面端工具条、工具菜单、Customize Toolbar 弹窗与通知气泡
