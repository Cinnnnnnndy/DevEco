@ObjectLink 与 @Observed：嵌套类对象的双向同步

@ObjectLink 装饰的变量不能在组件内初始化，必须由父组件传入被 @Observed 装饰的类实例。

@Observed
class Price { value: number = 0 }

@Component
struct PriceLabel {
  @ObjectLink price: Price;
}
