# Device Box · 多台画布的排布与比例规则

多台画布有两种排布：**真实尺寸**（默认）和**等宽瀑布流**，在画布右上角切换。两种排布共用同一套排序规则和缩放控件。

## 一、共用规则

**排序**：按断点从小到大排，依次是 xs、sm、md、lg、xl，也就是手表、手机、折叠屏、平板和三折叠、电脑和大屏。断点相同的，按加进画布的先后排。这样从左往右、从上往下看，就是一次「一多」从小屏走到大屏。

**加减设备**：新设备按断点插到对应位置，其余设备平移让位，有 0.35 s 的过渡，不整体重排。只剩一两台时，会多出一个「再加一台」的空位。

**缩放控件**（画布右上角，只在多台画布里出现）：

| 操作 | 效果 |
|---|---|
| − / +，或 ⌘− / ⌘+，或按住 ⌘ 滚动 | 倍率按 50 / 67 / 80 / 100 / 125 / 150 / 200% 逐档变化 |
| 适应，或 ⌘0 | 回到 100%：重新计算，让画布刚好放下所有设备 |
| 1:1（只在真实尺寸下有） | 按显示器上的实物大小显示，1 mm = 3.78 px |

**什么时候自动重算**：处在「适应」状态时，设备增减、画布变宽变窄、三折叠切屏、折叠屏开合，都会重新计算比例。手动缩放过以后会一直保持你设的倍率，直到点「适应」。

## 二、真实尺寸

1. **同一个比例尺**：所有设备都用同一个「每毫米多少像素」，按机身外形尺寸（mm）来画，所以设备之间的大小关系是真的。三折叠分别按单屏 74 mm、双屏 143 mm、三屏 219 mm 宽来画；折叠屏合上和展开也分开算。
2. **排法**：按排序依次从左往右放，放不下就换行。每一行底边对齐，就像把设备并排立在桌面上。行与行之间留 74 px，用来放名称和结论标签。
3. **适应比例怎么算**：在 1.0 到 3.0 px/mm 之间，找出能让所有行不上下滚动就放下的最大比例。
   - 设备太多、算出来小于 1.0 时，按 1.0 画，画布改成可以上下滚动，提示「已到最小比例」。这样手机最窄也有约 75 px，不会小到看不出布局。
   - 设备少、算出来大于 3.0 时，按 3.0 画，避免一两台设备被放大得失真。
4. **超大设备**：机身超过 400 mm 的设备（比如智慧屏）按 1/5 画，标签上写明「按 1/5 显示」。
5. **屏幕里的内容**：按同一物理比例缩小（1 mm ≈ 4.6 vp），所以文字在每台设备上的物理大小相同。小屏上字小，这是真实比例本来的样子；要看清细节，就双击这台单独看。

## 三、等宽瀑布流

1. **列数**：每列目标宽 300 px × 缩放倍率；列数是画布宽度能放下的最多列数，最少 2 列、最多 6 列，余下的宽度平均分给各列。放大一档，列就变宽、列数变少。
2. **跨列**：横屏设备（宽高比 ≥ 1.3，包括平板、电脑、三折叠三屏、车机、智慧屏）在 3 列及以上时跨 2 列，其余设备占 1 列。
3. **设备宽度 = 格子宽 × 形态系数**：

   | 形态 | 系数 |
   |---|---|
   | 手表 | 0.42 |
   | 手机、折叠屏合上、三折叠单屏（竖长条） | 0.62 |
   | 折叠屏展开、三折叠双屏（接近方形） | 0.9 |
   | 横屏设备 | 1（铺满所跨的列） |

   高度按设备自己的宽高比算，在格子里水平居中。
4. **落位**：按排序逐台放进当前最矮的那一列。跨 2 列的设备，找相邻两列中较高那列最矮的位置。高度一样时取最左边。
5. **屏幕里的内容**：不按物理比例缩，按屏幕像素直接显示，这样每台上的文字都看得清。这个模式用来看细节，真实尺寸用来看比例关系。

## 四、为什么这样定

- 默认用真实尺寸：一多检查要看的是同一个页面在不同大小的屏上怎么排，大小关系画错了，判断就会错。
- 留着瀑布流：真实尺寸下手表和手机里的字太小，看文字截断这类细节时，切到瀑布流更方便。
- 比例上下限和超大设备按 1/5 画，都是为了不让一台设备把画布占满，也不让小设备小到看不清。
