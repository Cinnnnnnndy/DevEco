# Device Box 多设备画布交互规则

更新：2026-11-03。分析报告：../../analysis/device-canvas-interaction/index.html。

## 查看与布局

默认七台、适配检查。适配检查按形态分配展示尺寸并保留宽高比；尺寸比较按机身毫米尺寸使用同一比例。设备尺寸是现有 Demo 的示意数据，正式支持型号需核验。

行从左起，初次排序 xs→sm→md→lg→xl，同断点按加入顺序。设备标题与屏幕上沿对齐。基准水平间距40、行间32，行高取最高设备外形高度加95文字与操作预留；格宽最小210。短设备下方允许因行高差产生空白，新行不能从前一台的右侧继续。

初始行宽按可用画布宽 / 0.8 分配；自动观看倍率优先兼顾宽高，低于65%时改用宽度适应并允许纵向滚动。全局手动缩放范围15%–400%，仅改变视口变换，不重新分行。指针缩放保持指向内容；按钮缩放围绕视口中心，滚动边界可能限制锚点补偿。

## 增删与单台展示

新增在末行接入，放不下时下一行左侧起排。自动总览可改变观看倍率；选中设备或手动缩放后保持倍率。

移出只改变画布集合，不改变连接和设备运行状态。修复移出所在行及后续行，前序行保持；选中项移出则选择原布局中距离最近的邻居。保留最近一次移出上下文，可撤销恢复集合、选中项、设备位置、单台展示倍率与滚动位置。

适配检查的单台放大/缩小：每档×1.25/×0.8，范围50%–200%；修复受影响行及后续行，补偿选中设备屏幕位置。尺寸比较下的单台缩放转入聚焦，以免破坏统一比例。

聚焦保存画布滚动位置，返回恢复。形态变更返回后按新外形修复受影响布局。真实视频流和输入会话未接入；当前仅为交互原型。

## 1:1 实物大小

首次显式选择1:1弹出100mm实体尺校准，用户确认后保存当前显示比例。取消不改变模式。外框宽高＝毫米宽高×校准像素/毫米，不额外加14px，不把大屏按1/5画，不因放不下自动缩小；超出视口可滚动。适应退出实物模式。换显示器、系统或浏览器缩放后重新校准；检测到显示参数变化时已校准状态失效。实体尺寸误差需实体尺测量，截图无法验证。

## 响应式与动作入口

≤1200px检查器按需抽屉，批量工具收进更多；≤720px长输入收起、设备列表按需展开，工具条换行。自动总览下改变窗口宽度可重新分行；用户接管视图后保持布局，显式整理才重新分行。设备标题选择，动作集中在底部设备名操作菜单，避免遮挡邻近标题。截屏、录屏仍为演示反馈。
