# explore · 视觉碎片

不定场景的视觉尝试放这里。每个碎片一个文件夹、自带页面，互不依赖；不进启动页目录，也不套 demo 那套「这一页解决什么」场景卡和消融记录。哪天某个碎片找到了用处，再按 README「终轮原则」落到对应 demo 或共享外壳里。

| 碎片 | 是什么 | 打开 |
|---|---|---|
| `glass/` | 毛玻璃实验台：DevEco 的界面碎片压在自然照片上，试经典毛玻璃五档厚度和液态玻璃 | `explore/glass/index.html` |
| `cards/` | 质感卡片：每张参考图（塑料膜、月晕、石塔、冰沙、苔原、彩虹薄雾、天水镜像、冰泉）加毛玻璃，各做一张内容相同的卡片，只换配色和质感 | `explore/cards/index.html` |

## glass · 毛玻璃实验台

双击 `glass/index.html` 就能看（file:// 下液态折射、字体都正常；也可以起个静态服务器）。左上角「毛玻璃实验台」展开是控制面板：

- **照片**：点缩略图换底图；「加照片」或者把照片直接拖进页面，只在这次打开里有效，不上传。
- **视图**：「桌面」是一组 DevEco 碎片（窗口、Agent 胶囊、通知、设备、运行条、交给 Agent 的输入框），宽屏下每块都能拖，看它压在不同景色上的样子；「材质」是同一套字和控件放在五档厚度和液态上并排比。
- **玻璃**：「经典毛玻璃」全部用模糊 + 染色；「液态」只把浮在内容上的控件（胶囊、运行条、输入框）换成液态，大面板还是毛玻璃。
- **深浅**：「随照片」时大面板跟整张照片的明暗走（一屏一个深浅，不花），液态控件跟自己底下那一块走，拖过亮处暗处会自己翻。
- **底色**：「取景色」从照片里挑一个又多又有颜色的主色混进玻璃的中性染色；蓝（主操作 / 选中）、紫（智能）、琥珀（在等你）这些语义色不跟着变。
- **调参**：模糊、染色、饱和是乘在五档上的倍率；颗粒、高光、折射、色散直接改。

材质 token 都在 `glass.css` 顶部：五档厚度 = 模糊半径 × 染色不透明度，深浅各一套。

### 换成自己的照片

1. 照片放进 `glass/photos/`（jpg / png / webp 都行）；
2. 在仓库根目录跑 `python3 explore/glass/tools/photos.py`：长边超过 2560 的会缩小，并重写 `photos/photos.js`（带每张照片的小色块网格，file:// 下判断明暗、取景色要用）；
3. 想给照片起名字，改 `photos.js` 里的 `name` 再跑一遍脚本，名字会保留。

`_standin-` 开头的四张是程序合成的占位风景图，真照片到了可以删掉再跑脚本。

### 已知限制

- 液态折射用的是 SVG 位移滤镜挂在 `backdrop-filter` 上，只有 Chromium 系（Chrome / Edge）支持；Safari、Firefox 只有高光和轻模糊，没有折射。
- Chromium 会把这类滤镜的坐标原点放在「元素 + 阴影外扩」的左上角，所以折射挂在元素里层一个不带阴影的 `.lq-surface` 上，投影留在外层（见 `glass.js`）。改液态样式时别把外投影加到 `.lq-surface` 上。

## cards · 质感卡片

每张参考图先用一张卡片代表，而且不画具体的东西：只抽三样——**序列**（结构和节奏）、**颜色对比**（用哪些色、各占多少）、**质感**（材质细节），全部由 `cards.js` 里的片元着色器（WebGL1）现算。卡片上只有名字、一行抽象描述和左上角的颜色占比条（每段宽度≈这个颜色在卡片里占的面积）；卡片下面是参考图画圈部分的裁切和「序列 / 对比 / 质感」三行说明。以后挑出有意思的，再往按钮、面板、背景这些形式上发展。

页面顶部可以切四个视图，每个着色器都同时算出这四种结果（`u_view`）：

| 视图 | 看什么 |
|---|---|
| 合成 | 三层叠在一起 |
| 序列 | 灰度的结构：条、环、带、流线怎么排 |
| 配色 | 平涂色块：用了哪些色、各占多少 |
| 质感 | 颜色换成中性灰：颗粒、纤维、反光 |

| 卡片 | 序列 | 对比 | 质感 | 跟着鼠标走的 |
|---|---|---|---|---|
| 毛玻璃 | 其余八张的主色排成宽窄不一的竖条 | 卡片里模糊成柔和过渡，边缘外是硬边 | 模糊、提饱和、浅色染色和亮边 | — |
| 塑料膜 | 两组斜褶，一密一疏，折线处是硬的 | 洋红、黑、白硬碰硬，背光的褶转紫 | 镜面反光（影棚反射 + 点光），高光压在印刷的字上 | 光源 |
| 月晕 | 同心光环被一条条横向暗带切开 | 大面积近黑、一小块冷白，环上淡黄淡紫 | 柔、散、胶片颗粒 | 光心 |
| 石塔 | 竖向凹槽，颜色从中间往两边一级级变 | 暖灰对钴蓝，几点暖黄 | 混凝土颗粒、雨痕、柱面明暗 | 中间那格 |
| 冰沙 | 颗粒沿同心弧一道道排开，每四道一条亮边 | 橙色同色系，高光跳出奶白 | 半透明小圆顶冰晶 | 光源 |
| 苔原 | 厚薄交替的倾斜地层，夹一条亮绿 | 土黄橄榄大面积，炭黑压底 | 草纤维、苔藓团块、玄武岩碎粒 | 地层视差 |
| 彩虹薄雾 | 主虹、反过来的副虹、中间一条暗天 | 灰蓝底上的低饱和粉彩 | 雾的颗粒和飘动，没有硬边 | 色带位置 |
| 天水镜像 | 水平对称轴，下面水纹越往下越疏 | 冷蓝紫对轴线一道暖橙 | 云絮与水纹 | 对称轴 |
| 冰泉 | 流函数的等值线：绕漩涡的白丝 | 青绿乳白深青同一冷色系 | 乳白通透、水花颗粒 | 漩涡 |

- 云、雾、水会慢慢动，卡片滑出视口就停，系统开了「减少动态效果」时停在一帧；WebGL 起不来时用 `--fallback` 渐变垫底。
- 塑料膜多画一层在内容上面（高光和折痕暗部压在字上），只在合成和质感视图里出现。
- `refs/` 是参考图画圈部分的裁切（红圈已抹掉）。毛玻璃卡片底下原来垫的是冰泉边的照片，现在换成了色条，`refs/glass-bg.jpg` 只作说明里的缩略图。
