# explore · 视觉碎片

不定场景的视觉尝试放这里。每个碎片一个文件夹、自带页面，互不依赖；不进启动页目录，也不套 demo 那套「这一页解决什么」场景卡和消融记录。哪天某个碎片找到了用处，再按 README「终轮原则」落到对应 demo 或共享外壳里。

| 碎片 | 是什么 | 打开 |
|---|---|---|
| `glass/` | 毛玻璃实验台：DevEco 的界面碎片压在自然照片上，试经典毛玻璃五档厚度和液态玻璃 | `explore/glass/index.html` |
| `cards/` | 质感卡片：每张参考图（瀑布、塑料膜、月晕、石塔、冰沙、苔原、彩虹薄雾、天水镜像、冰泉）加毛玻璃各一张卡片，不画具体的东西，只留渐变、光和质感；玻璃参照苹果的做法用着色器现算 | `explore/cards/index.html` |

## glass · 毛玻璃实验台

双击 `glass/index.html` 就能看（file:// 下液态折射、字体都正常；也可以起个静态服务器）。左上角「毛玻璃实验台」展开是控制面板：

- **照片**：点缩略图换底图；「加照片」或者把照片直接拖进页面，只在这次打开里有效，不上传。
- **视图**：「桌面」是一组 DevEco 碎片（窗口、Agent 胶囊、通知、设备、运行条、交给 Agent 的输入框），宽屏下每块都能拖，看它压在不同景色上的样子；「材质」是同一套字和控件放在五档厚度和液态上并排比。
- **玻璃**：「经典毛玻璃」全部用模糊 + 染色；「液态」只把浮在内容上的控件（胶囊、运行条、输入框）换成液态，大面板还是毛玻璃。
- **深浅**：「随照片」时大面板跟整张照片的明暗走（一屏一个深浅，不花），液态控件跟自己底下那一块走，拖过亮处暗处会自己翻。
- **底色**：「取景色」从照片里挑一个又多又有颜色的主色混进玻璃的中性染色；蓝（主操作 / 选中）、紫（智能）、琥珀（在等你）这些语义色不跟着变。
- **调参**：模糊、染色、饱和是乘在五档上的倍率；颗粒、高光、折射、色散直接改。

材质 token 都在 `glass.css` 顶部：五档厚度 = 模糊半径 × 染色不透明度，深浅各一套。

### 换成自己的照片

1. 照片放进 `glass/photos/`（jpg / png / webp 都行）；
2. 在仓库根目录跑 `python3 explore/glass/tools/photos.py`：长边超过 2560 的会缩小，并重写 `photos/photos.js`（带每张照片的小色块网格，file:// 下判断明暗、取景色要用）；
3. 想给照片起名字，改 `photos.js` 里的 `name` 再跑一遍脚本，名字会保留。

`_standin-` 开头的四张是程序合成的占位风景图，真照片到了可以删掉再跑脚本。

### 已知限制

- 液态折射用的是 SVG 位移滤镜挂在 `backdrop-filter` 上，只有 Chromium 系（Chrome / Edge）支持；Safari、Firefox 只有高光和轻模糊，没有折射。
- Chromium 会把这类滤镜的坐标原点放在「元素 + 阴影外扩」的左上角，所以折射挂在元素里层一个不带阴影的 `.lq-surface` 上，投影留在外层（见 `glass.js`）。改液态样式时别把外投影加到 `.lq-surface` 上。

## cards · 质感卡片

每张参考图先用一张卡片代表，不画具体的东西，但要留住它的**渐变**、**光感**和**质感**。玻璃参照苹果的做法全部用着色器（WebGL1）现算，卡片上的字压在一块液态玻璃上。最上面放大的是最新加的一张（瀑布），下面九张；每张卡片下面是参考图画圈部分的裁切和「渐变 / 光感 / 质感」三行说明。以后挑出有意思的，再往按钮、面板、背景这些形式上发展。

每张卡片一个 WebGL 上下文，分四步画（都在 `cards.js`）：

| 步骤 | 做什么 |
|---|---|
| bg 背景光场 | 这张参考图的颜色排成发光的渐变，画进一张带 mipmap 的贴图；四周多画一圈，折射到卡片外也有东西可取 |
| fx 玻璃 | 每张卡片自己的高度场 → 法线 → 折射偏移 + 色散（RGB 各偏一点）+ 磨砂（按 mip 级取模糊，每个像素转一个随机角度，糊得匀、带点磨砂颗粒）+ 菲涅尔反光 + 高光 + 内部发光 |
| dn 缩小 | 把 fx 的结果缩进一张小贴图、生成 mipmap，给下一步取模糊 |
| ui 液态玻璃片 | 按 `.plate` 的位置和圆角画字底下那块玻璃：边缘像透镜一样把底下往里压、分出色边，中间磨砂、提饱和，边上一道随光源转的亮线；再加泛光、暗角和抖动（防色带） |

| 卡片 | 渐变 | 光感 | 质感 | 跟着鼠标走的 |
|---|---|---|---|---|
| 瀑布 | 苔绿岩石的暗底往右上的太阳变亮，底部水雾抬成乳白 | 逆光：水幕薄处透出苔绿、厚处发白，雾里几道斜光 | 竖向水幕按厚薄折射、竖向拉长的磨砂，越往下越散成雾（会动） | 光源 |
| 毛玻璃 | 另外九张的主色排成竖条，上浅下深 | 透镜边一圈亮线，对面一道弱的内反光，底下一片淡影 | 清透的液态透镜 + 字底下的磨砂玻璃片 | 透镜 |
| 塑料膜 | 洋红从深梅到亮粉，背光的褶转紫 | 影棚光：柔光箱和灯管映在褶上 | 皱起的镀铝膜（背景贴图当环境光反射），黑标签是深色亮面玻璃 | 光源 |
| 月晕 | 近黑夜空里一小块冷白，一圈淡黄淡紫 | 薄云把月光打散成光晕，云边镶亮边 | 横向的云是磨砂玻璃条，慢慢往左漂 | 月亮 |
| 石塔 | 两边钴蓝、中间暖灰、几点暖黄灯 | 每根柱子一道竖向高光，柱缝暗下去 | 长虹玻璃：十三根竖柱把颜色折成一级一级，柱顶从中间往两边降（石塔的序列） | 光源 |
| 冰沙 | 同一个橙：中心杏色往外到砖红 | 每颗冰粒是个小透镜，奶白高光，背光那侧透暖光 | 沿同心弧排开的碎冰晶粒，每五道一条亮边 | 光源 |
| 苔原 | 浅灰、土黄、橄榄、亮苔绿，炭黑压底 | 每层上沿一道斜面接光，下面落浅影 | 叠起来的有色玻璃，有的磨砂有的清透，透出草丛和苔藓团 | 光源 |
| 彩虹薄雾 | 灰蓝往下变暖白，两道粉彩虹 | 主虹里面亮、两道虹之间暗，雾里几道斜光 | 飘着的磨砂雾，把虹糊开又露出来（会动） | 虹的圆心 |
| 天水镜像 | 深蓝到淡紫到地平线的暖橙，下面倒过来偏冷 | 太阳贴着地平线，水面一条碎金光路 | 会动的水面玻璃，越远水纹越细 | 太阳（左右） |
| 冰泉 | 乳白浅青到湖蓝到深青 | 水面把光聚成亮网，天光浮在水面 | 绕漩涡流的水面，乳白水丝顺着流（会动） | 漩涡 |

- 会动的卡片只在进入视口时画（约 30fps），静态的只在鼠标移动或尺寸变化时重画；系统开了「减少动态效果」时停在一帧。
- WebGL 起不来时用 `--fallback` 渐变垫底，字底下换成 CSS 毛玻璃（`--plate-fb`）。
- 磨砂靠 `EXT_shader_texture_lod` 按 mip 级取；没有这个扩展的机器退成普通的偏置取样，不转随机角度，糊得没那么匀。
