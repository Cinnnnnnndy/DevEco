# explore · 视觉碎片

不定场景的视觉尝试放这里。每个碎片一个文件夹、自带页面，互不依赖；不进启动页目录，也不套 demo 那套「这一页解决什么」场景卡和消融记录。哪天某个碎片找到了用处，再按 README「终轮原则」落到对应 demo 或共享外壳里。

| 碎片 | 是什么 | 打开 |
|---|---|---|
| `glass/` | 毛玻璃实验台：DevEco 的界面碎片压在自然照片上，试经典毛玻璃五档厚度和液态玻璃 | `explore/glass/index.html` |
| `cards/` | 质感色卡：每张参考图（瀑布、塑料膜、月晕、石塔、冰沙、苔原、彩虹薄雾、天水镜像、冰泉）加毛玻璃，先用照片纹理算法算成纹理、再抽象成一张色卡；点进去是工作台，调配方参数、看它做成手机壁纸和横幅 | `explore/cards/index.html` |

## glass · 毛玻璃实验台

双击 `glass/index.html` 就能看（file:// 下液态折射、字体都正常；也可以起个静态服务器）。左上角「毛玻璃实验台」展开是控制面板：

- **照片**：点缩略图换底图；「加照片」或者把照片直接拖进页面，只在这次打开里有效，不上传。
- **视图**：「桌面」是一组 DevEco 碎片（窗口、Agent 胶囊、通知、设备、运行条、交给 Agent 的输入框），宽屏下每块都能拖，看它压在不同景色上的样子；「材质」是同一套字和控件放在五档厚度和液态上并排比。
- **玻璃**：「经典毛玻璃」全部用模糊 + 染色；「液态」只把浮在内容上的控件（胶囊、运行条、输入框）换成液态，大面板还是毛玻璃。
- **深浅**：「随照片」时大面板跟整张照片的明暗走（一屏一个深浅，不花），液态控件跟自己底下那一块走，拖过亮处暗处会自己翻。
- **底色**：「取景色」从照片里挑一个又多又有颜色的主色混进玻璃的中性染色；蓝（主操作 / 选中）、紫（智能）、琥珀（在等你）这些语义色不跟着变。
- **调参**：模糊、染色、饱和是乘在五档上的倍率；颗粒、高光、折射、色散直接改。

材质 token 都在 `glass.css` 顶部：五档厚度 = 模糊半径 × 染色不透明度，深浅各一套。

### 换成自己的照片

1. 照片放进 `glass/photos/`（jpg / png / webp 都行）；
2. 在仓库根目录跑 `python3 explore/glass/tools/photos.py`：长边超过 2560 的会缩小，并重写 `photos/photos.js`（带每张照片的小色块网格，file:// 下判断明暗、取景色要用）；
3. 想给照片起名字，改 `photos.js` 里的 `name` 再跑一遍脚本，名字会保留。

`_standin-` 开头的四张是程序合成的占位风景图，真照片到了可以删掉再跑脚本。

### 已知限制

- 液态折射用的是 SVG 位移滤镜挂在 `backdrop-filter` 上，只有 Chromium 系（Chrome / Edge）支持；Safari、Firefox 只有高光和轻模糊，没有折射。
- Chromium 会把这类滤镜的坐标原点放在「元素 + 阴影外扩」的左上角，所以折射挂在元素里层一个不带阴影的 `.lq-surface` 上，投影留在外层（见 `glass.js`）。改液态样式时别把外投影加到 `.lq-surface` 上。

## cards · 质感色卡 + 工作台

每张参考图从照片本身出发：取画圈的那一块，交给 `tools/texture.py` 里的照片纹理算法变成一张抽象纹理（光、渐变和质感都是照片自己的像素），再抽象到最后一步——沿它自己的主方向拖一长刀、糊掉细节、按取出来的六个颜色重新上色，剩下的只有颜色、占比和过渡，就是一张色卡。

### 色卡页（`index.html`）

- 十张色卡：上面是最抽象的一版（`tex/abs/`），鼠标移上去换成纹理（`tex/`）；右上角「色卡 / 纹理」整页切换，记在本机。
- 中间的色条按各色占比分宽，下面是六个颜色，按亮度从暗到亮。
- 卡片由 `deck.js` 按 `cards-data.js` 的顺序生成，颜色和占比来自 `tex/data.js`。直接双击打开也能看。

### 工作台（`workbench.html#<名字>`）

点一张色卡进来。左边是参数，和 `texture.py` 的配方一一对应；右边是主图、这一版的色卡，下面是它在几个场景里的样子。起点是 `tex/base/<名字>.webp`（配方里能调的那几步之前的一张），后面几步由 `workbench.js` 用 WebGL2 实时重做，所以默认参数下看到的就是色卡页上那张纹理。

| 参数组 | 做什么 |
|---|---|
| 抽象度 | 沿主路径两头各拖 0.35 个卡片高、糊一层、按调色板渐变映射；拉到 1 就是色卡页上那张 |
| 取景 | 缩放、平移、旋转 |
| 拖曳曝光 · 两层 | 路径（平拖 / 绕圈 / 放射）、方向或中心、长度、单向拖尾；第二层带占比 |
| 像素拉伸 | 取一行（或一列）拉满，只留序列，再乘回原来的明暗 |
| 油画化 | 各向异性 Kuwahara（结构张量 → 两次高斯 → 8 扇区多项式权重），半径、占比；留住原图亮处 |
| 颜色 | 曝光、提亮暗部、中间调、饱和、冷暖；「色卡化」按调色板映射，「色阶」把映射切成几档 |
| 光 | 泛光和阈值、底部水雾、颗粒、暗角 |
| 流动 | 主图顺着第一层的路径慢慢流（系统开了「减少动态效果」时不流） |

- **手机壁纸**：锁屏和桌面各一张，壁纸在主图上再抽象一层（「再抽象」）、压暗一点；「取景」在纹理里左右挪。桌面图标的颜色轮流取调色板。
- **横幅**：3 : 1 的四种变形——条带（只取一列横着拉满）、镜像（左右对折）、渐隐（左边渐成调色板里的一个纯色，留给文字）、色块（按占比切成竖条，纹理只剩明暗）。
- 场景里的字用白还是深色：每次重画后把每个场景画一张很小的读回来，量字底下那一块的亮度再定。
- 参数停下来 0.3 秒后，从一张 48 像素宽的小图用 k-means（Lab，色度加权，和 `texture.py` 一样）重取调色板；默认参数时直接用 `tex/data.js` 里算好的。
- 每张的参数存在本机（`localStorage`），「恢复默认」清掉；「复制参数」把参数和调色板以 JSON 复制出来，可以照着改 `cards-data.js` 里的默认值。
- 工作台要用 WebGL2，而且直接双击打开（file://）时浏览器不让把图片交给 WebGL：会显示提示和 `texture.py` 算好的静态图。在仓库根目录跑 `python3 -m http.server`，打开 `http://localhost:8000/explore/cards/workbench.html`。
- 拖滑块时母图先用半分辨率、场景一秒最多重画 8 次，松手再全分辨率重画一次。油画化的半径上限 8：再大一次绘制太久，显卡可能被系统重置（页面会提示刷新）。

### 纹理算法（`tools/texture.py`）

| 做法 | 出处 | 干什么 |
|---|---|---|
| 拖曳曝光 | 摄影的「有意识的相机移动」（ICM） | 每个像素沿设计好的路径（竖、横、绕圈、放射）把照片积分起来，单向拖尾或两头均匀 |
| 流线卷积 | Cabral & Leedom 1993，走向用结构张量（Kyprianidis 等） | 沿照片自己的纹理走向抹开（现在的配方没用上，留作备用） |
| 各向异性 Kuwahara | Kyprianidis、Kang、Döllner 2009，多项式权重版 | 油画式抽象，保边、按走向压成色块（numba 编译） |
| 图像绗缝 | Efros & Freeman 2001 | 小块按重叠误差挑、沿最小误差路径缝，拼成没有具体物体的更大纹理；可以给一张「不能取」的掩码 |
| 纹理迁移 | 同一篇第 4 节 | 按一张参数化的构图挑块，构图是设计的、纹理是照片的 |
| 像素拉伸 | slit-scan | 取一行竖着拉满，只留下横向的序列 |
| 取色 | k-means（Lab 空间，色度 ×1.8） | 取六个主色、按亮度排、带占比；面积小但鲜的颜色也能单独成一类 |
| 最抽象的一版 | — | 沿主路径两头拖、糊一层、按调色板渐变映射，只留 15% 原来的颜色 |
| 沿流向修补 | — | 认出画上去的红圈，沿拖曳方向多尺度扩散补掉，拖完不留接缝 |

| 卡片 | 配方 |
|---|---|
| 瀑布 | 竖向拖曳（两头 170 像素 + 单向拖尾 60 像素），底部水雾、泛光 |
| 毛玻璃 | 另外九张各取中间一条竖条，按设计好的宽度拼起来 |
| 塑料膜 | 只从膜上取块绗缝成没有字的皱膜 → 去掉原来的明暗只留褶皱 → 用照片里量出的暗 / 中 / 高光 / 紫按一道斜向反光重新上色 → 轻 Kuwahara |
| 月晕 | 横拖 80 像素 + 从月亮往外放射拖尾，月亮留一点形，大半径泛光 |
| 石塔 | 在柱子最宽的那一行像素拉伸，加上同几列从上到下的颜色和竖拖过的明暗 |
| 冰沙 | 放大后各向异性 Kuwahara，再绕杯心短拖 |
| 苔原 | 纹理迁移：参数画的倾斜地层 ← 照片里的草、苔、石头小块（三轮，48→22 像素），顺地层轻拖 |
| 彩虹薄雾 | 绕虹心转着拖，130 + 40 像素两层 |
| 天水镜像 | 横向拖曳，120 + 36 像素两层 |
| 冰泉 | 只用那潭水绗缝成整张，再绕中心轻轻转着拖 |

重新生成（在仓库根目录）：

```bash
pip install numpy opencv-python numba
python3 explore/cards/tools/texture.py            # 全部；苔原的纹理迁移最慢，十来分钟
python3 explore/cards/tools/texture.py fall glass # 只生成这几张（毛玻璃是拿其余九张拼的，放最后）
```

- `tools/src/` 是参考照片画圈附近的原图裁切，红圈还在，脚本自己识别、修补。
- 输出：`tex/<名字>.webp` 纹理（瀑布 1600×1000，其余 800×1000）；`tex/base/` 工作台的起点；`tex/abs/` 最抽象的一版；`tex/data.js` 每张的调色板、占比和渐变映射用的亮度范围（脚本生成，别手改）。
- 工作台的默认参数在 `cards-data.js`，和配方对应；改了配方记得同步那边的默认值，不然工作台默认看到的和纹理图对不上。
- `refs/` 是参考图画圈部分的小裁切，只作工作台「这张是怎么来的」的缩略图。
