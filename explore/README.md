# explore · 视觉碎片

不定场景的视觉尝试放这里。每个碎片一个文件夹、自带页面，互不依赖；不进启动页目录，也不套 demo 那套「这一页解决什么」场景卡和消融记录。哪天某个碎片找到了用处，再按 README「终轮原则」落到对应 demo 或共享外壳里。

| 碎片 | 是什么 | 打开 |
|---|---|---|
| `glass/` | 毛玻璃实验台：DevEco 的界面碎片压在自然照片上，试经典毛玻璃五档厚度和液态玻璃 | `explore/glass/index.html` |
| `cards/` | 质感卡片：每张参考图（瀑布、塑料膜、月晕、石塔、冰沙、苔原、彩虹薄雾、天水镜像、冰泉）加毛玻璃各一张卡片；画面是一套照片纹理算法从参考照片本身算出来的，不画图形 | `explore/cards/index.html` |

## glass · 毛玻璃实验台

双击 `glass/index.html` 就能看（file:// 下液态折射、字体都正常；也可以起个静态服务器）。左上角「毛玻璃实验台」展开是控制面板：

- **照片**：点缩略图换底图；「加照片」或者把照片直接拖进页面，只在这次打开里有效，不上传。
- **视图**：「桌面」是一组 DevEco 碎片（窗口、Agent 胶囊、通知、设备、运行条、交给 Agent 的输入框），宽屏下每块都能拖，看它压在不同景色上的样子；「材质」是同一套字和控件放在五档厚度和液态上并排比。
- **玻璃**：「经典毛玻璃」全部用模糊 + 染色；「液态」只把浮在内容上的控件（胶囊、运行条、输入框）换成液态，大面板还是毛玻璃。
- **深浅**：「随照片」时大面板跟整张照片的明暗走（一屏一个深浅，不花），液态控件跟自己底下那一块走，拖过亮处暗处会自己翻。
- **底色**：「取景色」从照片里挑一个又多又有颜色的主色混进玻璃的中性染色；蓝（主操作 / 选中）、紫（智能）、琥珀（在等你）这些语义色不跟着变。
- **调参**：模糊、染色、饱和是乘在五档上的倍率；颗粒、高光、折射、色散直接改。

材质 token 都在 `glass.css` 顶部：五档厚度 = 模糊半径 × 染色不透明度，深浅各一套。

### 换成自己的照片

1. 照片放进 `glass/photos/`（jpg / png / webp 都行）；
2. 在仓库根目录跑 `python3 explore/glass/tools/photos.py`：长边超过 2560 的会缩小，并重写 `photos/photos.js`（带每张照片的小色块网格，file:// 下判断明暗、取景色要用）；
3. 想给照片起名字，改 `photos.js` 里的 `name` 再跑一遍脚本，名字会保留。

`_standin-` 开头的四张是程序合成的占位风景图，真照片到了可以删掉再跑脚本。

### 已知限制

- 液态折射用的是 SVG 位移滤镜挂在 `backdrop-filter` 上，只有 Chromium 系（Chrome / Edge）支持；Safari、Firefox 只有高光和轻模糊，没有折射。
- Chromium 会把这类滤镜的坐标原点放在「元素 + 阴影外扩」的左上角，所以折射挂在元素里层一个不带阴影的 `.lq-surface` 上，投影留在外层（见 `glass.js`）。改液态样式时别把外投影加到 `.lq-surface` 上。

## cards · 质感卡片

每张参考图先用一张卡片代表。这一版不再用代码去画东西：每张卡片都从参考照片本身出发，取画圈的那一块，交给 `tools/texture.py` 里的照片纹理算法，变成一张抽象的纹理——光、渐变和质感都是照片自己的像素。页面上 `cards.js` 再让纹理顺着拖曳方向慢慢流、加鼠标的柔光，并在字底下画一块液态玻璃。最上面放大的是最新加的一张（瀑布），下面九张；每张卡片下面是参考图画圈部分的裁切和「取样 / 算法 / 留下」三行说明，页面最后列了用到的算法和出处。

### 纹理算法（`tools/texture.py`）

| 做法 | 出处 | 干什么 |
|---|---|---|
| 拖曳曝光 | 摄影的「有意识的相机移动」（ICM） | 每个像素沿设计好的路径（竖、横、绕圈、放射）把照片积分起来，单向拖尾或两头均匀 |
| 流线卷积 | Cabral & Leedom 1993，走向用结构张量（Kyprianidis 等） | 沿照片自己的纹理走向抹开 |
| 各向异性 Kuwahara | Kyprianidis、Kang、Döllner 2009，多项式权重版 | 油画式抽象，保边、按走向压成色块（numba 编译） |
| 图像绗缝 | Efros & Freeman 2001 | 小块按重叠误差挑、沿最小误差路径缝，拼成没有具体物体的更大纹理；可以给一张「不能取」的掩码 |
| 纹理迁移 | 同一篇第 4 节 | 按一张参数化的构图挑块，构图是设计的、纹理是照片的 |
| 像素拉伸 | slit-scan | 取一行竖着拉满，只留下横向的序列 |
| 沿流向修补 | — | 认出画上去的红圈，沿拖曳方向多尺度扩散补掉，拖完不留接缝 |

| 卡片 | 配方 |
|---|---|
| 瀑布 | 竖向拖曳（两头 170 像素 + 单向拖尾 60 像素），底部水雾、泛光 |
| 毛玻璃 | 另外九张各取中间一条竖条拼起来；页面上加跟着鼠标的液态透镜 |
| 塑料膜 | 只从膜上取块绗缝成没有字的皱膜 → 去掉原来的明暗只留褶皱 → 用照片里量出的暗 / 中 / 高光 / 紫按一道斜向反光重新上色 → 轻 Kuwahara |
| 月晕 | 横拖 80 像素 + 从月亮往外放射拖尾，月亮留一点形，大半径泛光 |
| 石塔 | 在柱子最宽的那一行像素拉伸，加上同几列从上到下的颜色和竖拖过的明暗 |
| 冰沙 | 放大后各向异性 Kuwahara，再绕杯心短拖 |
| 苔原 | 纹理迁移：参数画的倾斜地层 ← 照片里的草、苔、石头小块（三轮，48→22 像素），顺地层轻拖 |
| 彩虹薄雾 | 绕虹心转着拖，130 + 40 像素两层 |
| 天水镜像 | 横向拖曳，120 + 36 像素两层 |
| 冰泉 | 只用那潭水绗缝成整张，再绕中心轻轻转着拖 |

重新生成（在仓库根目录）：

```bash
pip install numpy opencv-python numba
python3 explore/cards/tools/texture.py            # 全部；苔原的纹理迁移最慢，十来分钟
python3 explore/cards/tools/texture.py fall glass # 只生成这几张（毛玻璃是拿其余九张拼的，放最后）
```

- `tools/src/` 是参考照片画圈附近的原图裁切，红圈还在，脚本自己识别、修补；`tex/` 是生成的纹理（瀑布 1600×1000，其余 800×1000）。
- 页面：瀑布、月晕、彩虹、天水镜像、冰泉会顺着拖曳方向慢慢流（两个相位交替淡入淡出），出视口就停，系统开了「减少动态效果」时不流。
- 纹理图本身就在卡片里（`img.tex`）：WebGL 起不来、或者直接双击打开（file:// 下浏览器不让把图片传进 WebGL）时，只显示这张图，字底下换成 CSS 毛玻璃；想看流动和液态玻璃，在仓库根目录起个静态服务器（例如 `python3 -m http.server`）再打开。
- `refs/` 是参考图画圈部分的小裁切，只作说明里的缩略图。
