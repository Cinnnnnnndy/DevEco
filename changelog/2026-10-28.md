## 设计模拟器 Device Hub 工具 → Device Box（10/27 13:01–16:15，PR #21 已合并）

### 1. 排列规则、液态玻璃、上线（13:01–15:26）
- 原话：「设定一下瀑布屏排列的规则和比例的调整规则」。规则写进了 `LAYOUT.md`：
  - 设备按断点从小到大排。
  - 缩放 50%–200%，支持「适应」和 ⌘+ / ⌘− / ⌘0。
  - 真实尺寸：所有设备用同一比例尺，底边对齐，比例限制在 1.0–3.0 px/mm，另有 1:1 实物大小，超过 400 mm 的设备按 1/5 画。
  - 等宽瀑布流：每列目标宽 300 px，2–6 列，按形态系数决定设备宽度，逐台放进最矮的那一列。
  - 这些数字都是我们先定的初值。
- 原话：「这个现在是毛玻璃效果并不是ios27的那种液态玻璃效果」「能找到这个的标准组件么」「ios的组件？」
  - 改成液态玻璃：边缘折射、高光、跟着指针走的反光。折射只在 Chrome 和 Edge 里看得到，Safari 会退回轻度模糊。
  - 标准件：Apple Design Resources 有 iOS 和 macOS 27 的 UI 套件（Figma、Sketch），原生代码是 SwiftUI `.glassEffect`、`UIGlassEffect`、`NSGlassEffectView`。网页只有社区实现，鸿蒙对应 ArkUI 和 HDS Material。
- 原话：「只用在这个devicebox的demo里」。**规则**：液态玻璃只用在 Device Box 里，组件库和其他 demo 都不动。
