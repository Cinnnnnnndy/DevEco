多设备画布：交互专利候选点

从用户触发、显示反馈、状态连续与可逆操作出发，形成可演示、可检索的创新方案。

研究主线

变化发生，操作上下文保持

在增删、缩放、形态切换与窗口变化时，用户不必重新寻找正在操作的设备。

研究边界

候选机制，尚未确认可授权

本报告为交互方案与交底素材；初步资料检索不能代替新颖性、创造性专项检索。

当前交付

规则 → 图示 → Demo 验证

七台示意设备；支持查看模式、稳定行布局、单台放大、聚焦返回、移出撤销与实物比例校准。

00 / 问题与机会

创新应围绕“变化后的连续操作”

不是将添加、移除、缩放等常见按钮分别申请，而是研究这些操作共同作用时的交互控制机制。

场景 A · 适配检查

增删比较对象后重新找设备

工程师正在检查手机商品页，加入电脑后手机被整体缩小、换位；当前任务被打断。

场景 B · 定位问题

总览与细节相互争夺空间

设计师需要同时看七种形态，又需要放大某一台检查；返回总览时应恢复原来的比较上下文。

场景 C · 宽窄切换

画布被辅助面板挤压

检查器与长工具条占据窄窗口；继续缩小全部设备会损失可读性，逐个塞空位则产生大面积空洞。

01 / 候选点总览

一条主线，五个交互候选点

建议以“多设备画布变化中的操作上下文保持”作为主案研究线，其他机制评估是否作为从属特征。

候选点用户触发研究中的区别组合Demo 状态
P1 增删连续性加入／移出设备活动设备锚点保持＋有序行修复＋移出可撤销已实现主要交互
P2 层级缩放全局缩放／放大单台视口缩放与排布分离＋单台展示变化＋尺寸模式保护已实现
P3 聚焦往返聚焦／返回画布保持设备集合、倍率、位置与选中对象的往返已实现画布上下文；真实会话待接入
P4 实物比例查看首次点击 1:1实物校准＋不自动缩小＋越界导航＋恢复适应已实现；需用户实体尺校准
P5 窄屏渐进显示缩窄窗口／打开检查器辅助面板让位＋最低可读倍率＋显式整理已实现主要响应式规则
02 / 排版契约

先规定行的结构，再放置设备

修正旧算法“寻找任意空位”的漂移：新行始终从左侧开始，不沿前一台右边界形成长列。

约束明确规则为什么
行的起点画布左侧统一边距；行内从左至右；禁止整行右悬避免截图中的左侧整块空白
行内与行间基准水平间距 40；下一行 y＝上一行顶部＋最高占位高度＋32短设备下方可留白，但不能把新行带到右侧
设备外形宽高比保持；适配检查可独立分配展示尺寸清晰查看与真实尺寸比较分开
文字与动作标题与元信息保持可读；超长省略；动作集中在底部设备名操作菜单避免跨设备文字与悬浮条相互遮挡
可读下限自动总览最低 65%；放不下允许滚动，手动可缩小不强求全部塞进一屏
P1 / 主案候选 · 加入

加入设备时，现有比较关系保持

用户希望增加比较对象，不意味着同意重置当前画布。新增对象的可发现性与旧对象的稳定性共同处理。

不变量

当前设备、设备顺序、手动倍率

既有设备不因新增而重新按断点插队；初次排布按断点，新加入按本轮加入顺序追加。

区别候选

加入行为与显示上下文关联

重点研究“已手动接管／自动总览”的分支，而非加入按钮本身。

效果验证

减少重新寻找与误操作

比较新增前后当前设备的屏幕位移、非目标设备位移和继续操作所需步骤。

P1 / 主案候选 · 移出

移出后修复受影响的行，并允许原位撤销

移出仅改变画布集合，不断开连接、不停止设备；与设备删除、租约释放区分。

布局变化

受影响行从左补位

前面的行保持；后续行按顺序重新分行。用户操作视图时，保留选中设备的屏幕锚点。

恢复行为

一次撤销恢复删除前布局

恢复设备集合、原选中项、单台展示大小、设备位置与滚动位置；本轮保留最近一次移出。

区别与边界

空间紧凑和操作稳定一起评估

普通自动补位已有大量先例。候选组合在于选择继承、锚点补偿与完整撤销；尚待专项检索。

P2 / 候选点 · 全局缩放

全局缩放只改变视口，不改变设备排布

用户以鼠标位置为观察锚点缩放；设备之间的左右、上下关系保持。

交互改变保持
＋／−／组合键全局观看倍率；以视口中心为观察锚点设备集合、行分组、设备自身形态
组合键＋滚轮全局观看倍率；以指针位置为观察锚点相对位置与阅读顺序
适应重算观看倍率并返回总览起点不主动重新整理设备位置
整理画布重新按当前宽度分行，再进入总览设备身份与应用示意状态
P2 / 候选点 · 单台放大

单台展示变化，与视口缩放分层处理

用户选中设备后点击放大，只改变该设备的展示分配；不改变设备实际分辨率与应用配置。

适配检查

独立放大与缩小

每次 ×1.25 或 ×0.8，范围 50%–200%；修复当前行及后续行，前面行不动。

尺寸比较

单台放大转入聚焦

避免一台被独立放大后，画布仍冒充统一尺寸比例；返回时恢复尺寸比较。

待验证

行修复范围与锚点冲突

位于边缘时滚动补偿受边界限制；候选效果应通过对照测试测量，不能预设为零位移。

P3 / 候选点 · 聚焦往返

从多台比较到单台操作，再回到原处

聚焦是临时的任务层级切换，退出后继续此前比较。

保存的上下文

集合、位置、倍率、选中项

本版保留画布布局、单台展示设置与进入聚焦前的滚动位置。

未在本版完成

真实调试会话与预览带

本版单台模式使用已有设备示意页；真实输入、视频流不中断及邻侧预览带属于后续验证。

区别候选

回到同一任务位置

单独看一个设备十分常见；需要检索“层级切换＋上下文继承＋形态变更返回”的具体组合。

P4 / 候选点 · 1:1 实物大小

1:1 对应实物外形，不因窗口小而缩水

本次修正固定像素换算、额外边框增量以及超大设备按 1/5 绘制的问题。

关键约束

1:1 与适应互不混用

外形宽高＝机身毫米尺寸 × 已校准比例。窗口放不下时尺寸不变，不继续缩小并显示 1:1。

退出与失效

恢复适应；换屏后重新校准

点击适应恢复总览；检测到显示参数变化时取消已校准状态，实际换屏仍需用户确认。

申请边界

校准本身不直接视为创新

候选在于校准、统一比例、越界查看、往返恢复的交互组合；尺寸数据库仍需型号核验。

P5 / 候选点 · 窄屏

空间不足时，先减少辅助占用

窄屏不等于把所有设备压到难以辨认；不让固定工具条或侧栏强占主要任务区域。

宽度条件界面反馈状态保持
≤1200px检查器默认收起，点击右上入口以抽屉打开；底部工具条可换行手动视图不因展开抽屉改变倍率
≤720px隐藏顶栏长输入；侧栏按需展开；操作区换行设备动作仍可从标题选择后访问
自动总览下窗口变化按新宽度重新分行；最低 65%保留设备集合与应用示意状态
手动视图下窗口变化保持现有排布，滚动查看；可显式整理优先保存用户已设定的倍率与顺序
03 / 操作体系

明确每个动作的对象与影响范围

画布管理、单台操作与设备生命周期分别处理，降低误解与误操作。

对象动作入口与反馈
画布集合添加、移出、撤销底栏添加常驻；移出在底部设备名操作菜单；撤销恢复最近一次移出
选中设备聚焦、放大、缩小、恢复大小标题选择；底部设备名操作菜单操作，避免悬浮条遮挡邻居
单台调试截屏、录屏、导航、键盘按设备能力提供；当前截屏／录屏为既有演示反馈，非真实文件输出
设备形态横竖屏、折叠、单／双／三屏单台视图操作；返回后依据新形态修复布局
全部设备全部截屏、全部录屏、复原场景收进更多；指当前画布集合，实际调试接口待接入
连接与配置断开、停止、释放、删除配置不绑定到画布移出；保留既有设备管理入口
04 / 交互状态机

相同操作，在不同上下文中有不同规则

状态显式可见；恢复动作与破坏性设备管理不混淆。

当前状态触发目标状态与反馈
自动总览增添设备允许重算观看倍率，但不打乱既有行位置
用户接管增删／单台放大保持倍率；修复受影响行；补偿选中设备位置
尺寸比较单台放大／缩小进入单台聚焦，返回后恢复统一尺寸比例
未校准点击 1:1展示校准对话框；取消不改变当前模式
已校准实物显示窗口变小尺寸保持，滚动查看；不得自动缩成适应
任意画布显式整理按当前宽度重新分行，回到总览起点

06 / 交底表达

用交互步骤描述候选保护内容

以下为交底提纲，不是已经确定保护范围的权利要求书。主张效果必须由对应控制机制支持。

主案描述草案

多设备画布变化中的连续操作

接收用户对设备集合或展示尺度的变更；依据当前选择、视口与行布局确定变化范围；更新受影响视图，保持操作目标可定位，并提供上下文恢复。

可评估的从属特征

按状态区分变化规则

增删行为、选中继承、行修复、局部展示、聚焦往返、校准比例与越界显示。避免无关联地拼接常规功能。

交底附件

关键帧与异常分支

每个点保留操作前、触发中、操作后、恢复后四帧；补充窄屏、空集合、断连、切屏、倍率失效等分支。

07 / 验证方案

用可测量结果支持交互效果

对比“每次全局重新排布”的基线与本版规则；以下是拟测指标，不是已取得的实验结论。

用例观察指标通过条件／记录方式
添加第八台非目标位移、当前目标屏幕位移手动倍率保持；旧设备不插队；记录锚点偏移
移出并撤销集合、位置、选择、倍率与滚动值恢复删除前上下文；实际连接状态不受移出影响
单台放大后恢复受影响行范围、重叠与阅读顺序前序行不动；受影响行有序；外形不拉伸
连续缩放行数、设备相对位置、指针锚点误差不因全局缩放重新分行；边界误差单独记录
校准后显示 100mm实体尺测量误差必须由用户或实机测量；屏幕截图不能证明实物大小
窄屏与窗口变更文字碰撞、按钮可达性、内容遮挡在 1440／1024／768／390 宽度逐项检查
