# Device Box 交互精调约束

保持现有设备示意与设计 token。默认七台适配检查。初始与整理采用有序行布局：行从左起、标题与屏幕上沿齐、行内40、行间32、行高按最高设备加标题元信息占位。最低总览倍率65%，超出滚动。

全局缩放不重排，围绕指针或视口中心；适应只改变观看倍率；整理才按新窗口宽度重新分行。添加在末行追加，放不下从下一行左起。移出仅影响画布，修复受影响行和后续行，保留最近一次撤销。单台放大50%—200%，按1.25/0.8改变，保持形态比例，恢复大小回到基准。尺寸比较模式单台缩放转聚焦，不破坏统一比例。

1:1首次使用需实体尺校准100mm；机身外框按毫米×校准比例，不加边框增量，不因窗口小而缩小，不对大屏按1/5画。校准取消无副作用；换显示参数重校准。

窄屏≤1200检查器抽屉、批量动作更多；≤720工具条换行、长输入收起。设备标题选择，动作放底部设备名操作菜单，不遮相邻设备。键盘可达与减少动画。

不得声称已实现真实调试输入、视频流、截屏文件和录屏输出；均需后端接入。专利候选点不能宣称已满足新颖性、创造性。
