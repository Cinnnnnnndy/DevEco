# 26.0 走查 · 流程清单

走查对象：DevEco Code 26.0 融合版本（DevEco Studio 内的 DevEco Code 插件，1.0.0-SNAPSHOT，模型 DevEco Code/GLM-5.1），macOS。
主线：**从安装到使用**。截图编号按收到的顺序，步骤编号按流程顺序。

## F1 · 从安装到第一次用 DevEco Code 建工程

用户：鸿蒙应用开发者，已装 DevEco Studio。
场景：拿到 DevEco Code 融合版本的插件包，装上后让它按一句话需求建工程、写 PRD。

| 阶段 | 步骤 | 截图 | 用户在做什么 |
|---|---|---|---|
| 安装 | 1 | `images/02` | 打开「设置 › 插件 › 已安装」，看 DevEco Code 当前版本 |
| 安装 | 2 | `images/03` | 点齿轮，选「从磁盘安装插件…」 |
| 安装 | 3 | `images/04` | 在文件选择框里找插件安装包 |
| 安装 | — | **缺页** | 安装进度、安装成功、是否需要重启 IDE |
| 进入 | — | **缺页** | 重启后第一次打开 DevEco Code：欢迎 / 登录 / 协议授权 / 模型选择 |
| 进入 | 4 | `images/01` | 打开 DevEco Code，面对新对话空态 |
| 使用 | 5 | `images/05` | 发出需求「开发工时记录鸿蒙 app，写 PRD 并建工程」；首发失败后重试 |
| 使用 | 6 | `images/06` | 选定项目名，Agent 建工程、读目录、跑待办清单 |
| 使用 | 7 | `images/07` | 同一会话往下走：Agent 停下，用户发「使用文件工具来操作打开」「编写 PRD 文档」推它继续 |
| 使用 | — | **缺页** | 完成态：工程创建结果、PRD 产出、在 DevEco Studio 中打开工程 |
| 换工程继续 | 8 | `images/08` | 打开 Agent 建好的 TimeTracker 工程：会话列表只剩「新对话」，之前的对话消失；重发需求两次报「ACP client is not connected」 |

另缺：侧栏「技能」「模型」两个入口点进去的页面。
