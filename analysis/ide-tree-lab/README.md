## 当前方案：20 / 20 / 16

新增 `#solution` 专属页面：箭头容器 20px、文件图标 20px、文件名字号 16px。默认缩进 20px，紧凑模式 16px，24px 作为对照；建议行高 28px、箭头槽至图标 4px、图文间距 4px。

三组目录内容一致，可统一切换 280 / 320 / 360px 侧栏宽度，并查看第 4 级名称的实际可用宽度。支持复制或下载标准与紧凑模式 CSS。实验室支持独立调整箭头容器，默认载入当前标准方案。

这些是待用户测试的设计建议，不是已验证的最佳参数。原来的 14 / 16 基础参考与竞品研究仍保留。

## 数据边界

所有竞品预览都是结构示意，不是截图或当前产品的精确复刻。IntelliJ / Fleet / Xcode 的数值为截图量级估算；Fleet 与 Xcode 样本有历史版本限制。Cursor / TRAE 使用 VS Code 上游基线，不是本品实测。原生 pt 与 CSS px 只比较逻辑量级。页面明确区分来源、估算和待验证的设计建议。

建议起点：字号 14px、图标 16px、箭头槽 16px、箭头槽至图标 4px、图文间距 6px、每级缩进 16px、行高 24px、基础留白 8px。它不是通用标准，仍需真实目录与用户测试。

## 本地预览与修改

无需安装依赖或构建。双击 `index.html`，或在此目录执行：

```sh
python3 -m http.server 4173
```

然后打开 http://localhost:4173。

- `data.js`：竞品预设、内容卡片、目录数据、来源。
- `app.js`：页面与交互。
- `styles.css`：视觉、主题、响应式布局。
- `index.html`：页面外壳与图标符号。

文件使用相对路径，可直接部署到 GitHub Pages 子目录。发布时在仓库 Settings → Pages 中选择 `main` 分支根目录。

视觉结构参考 https://cinnnnnnndy.github.io/DevEco/，本项目代码、示意组件与内容为独立实现。

## 完整 IDE 效果展示

`#ide` 基于所提供 Int UI Kit 的 Main Window 浅色组件（Figma 节点 `7070:138481`）重新组合为交互页面。工具栏高 40px、标签栏 41px、两侧工具条 41px、状态栏 29px；保留 UI Kit 原始图标资源。文件树使用当前 20 / 20 / 16、4px 图文间距、28px 行高参数，原始 16px 图形居中放入 20px 图标容器。

支持 16 / 20 / 24px 缩进、260–420px 侧栏宽度、拖动分隔线、键盘调整宽度、展开/收起目录、切换与关闭编辑器标签、文件搜索、终端显隐与宽屏展示。代码与运行日志仅用于设计演示。`ide-preview.js` / `ide-preview.css` 为效果页实现。

参考：https://www.figma.com/design/3q89XhaMGImDOPJwvfEpd7/Int-UI-Kit--Community-?node-id=7070-138481
