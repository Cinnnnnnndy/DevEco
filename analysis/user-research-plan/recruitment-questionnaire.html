开场说明

我们正在招募外部鸿蒙开发者，了解开发准备、编码、测试验证与交付，以及 AI 和 DevEco Code 的实际使用经历，为 DevEco 体验优化与后续规划提供依据。企业团队、小团队、个人开发者及有实际练习工程的学习者均可报名；没有使用 AI 或 DevEco Code，也欢迎参与。

填写预计 10–15 分钟，获邀后将另行安排一次约 60–90 分钟的访谈或任务体验，具体形式与时长会提前说明。请根据真实经历作答，没有标准答案。除明确标注时间范围的题目外，请围绕您最近参与的一个鸿蒙项目填写；开发中、已交付和暂停的项目都可以。

填写与提交均为自愿，答案用于本次研究招募；联系方式仅用于您同意的研究联系。请勿填写代码、账号、客户身份或保密资料。录音、录屏、展示材料及后续复访会另行确认。
