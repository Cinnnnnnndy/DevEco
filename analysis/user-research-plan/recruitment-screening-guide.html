外部用户招募筛选与预约说明

版本：2026-11-09 · 配套14题精简问卷

问卷只做初筛，预计4–6分钟。分组和研究邀请由预约核验确认，问卷页面为审阅稿，不收集答案。深入需求、任务回溯和满意度保留在正式访谈。

一、招募范围与主配额

外部近6个月有本人鸿蒙任务者为常规对象；更早经历作为历史 / 停用专题核验。内部用户由业务团队定向邀请，不填外部问卷，近3个月实际使用DevEco，来源单独记录。

画像主类累计建议区间核验依据
P1 头部互联网及同类大型研发团队12–16人多团队协作、组织级工程平台或专门工具链支持
P2 中厂8–10人稳定分工，工程支持主要围绕业务项目
P3 小团队与个人开发者10–14人少量成员或个人承担多环节、自行组合工具
合计30–40人多轮累计独立人数，复访只增加人次

目标比例约40%、25%、35%，是研究覆盖参考。内部6–10人包含在总数内，按工程体系归组；生态伙伴记业务标签。Q01–Q04给出行业、岗位、组织研发人数和项目人数，预约时核实协作与组织背景，不能只看人数或公司名分类。

同一外部企业原则上≤2人，头部配对访谈≤3人，争取3–4家外部重点企业；内部≥3个业务团队，开发≥4人、测试 / 发布≥1人。P3中小团队和独立开发 / 学习者分别争取≥4人。

二、题目、跳题与用途

题号用途配置
Q01–Q04行业、岗位、组织与项目人数分别保留组织研发人数和项目人数，结合实际协作与工具支持判定画像。允许未知或无所属组织
Q05项目数量正在做首个项目且已动手选1个。尚未实际参与过（0个）结束，记不清进入核验
Q06最近本人任务时间与Q05一起看。近6个月有本人任务者走常规流程，更早进入历史专题核验，时间未知待确认
Q07高频任务及流程覆盖多选最多3项，分别记录测试验证和性能调优，预约时核实本轮需要的实际任务
Q08其他平台的同类任务经历记录实际做过的可比平台。最后三项均须单独选择，所有回答均继续填写
Q09Studio近4周频率独立记录 Studio 近期、历史、从未与未知使用状态。鸿蒙任务时间以Q06为准

Q12AI近4周频率高频≥3天 / 周，近期低频少于3天，另记近月未用但以前用过、从未用过
Q13最常用AI工具Q12近期用过者回答。近期未用或从未用过跳至Q14，台账记未展示
Q14本次意愿暂不参加结束。想先了解者先说明任务形式、时长和资料要求，再确认参与意愿

问卷共14道编号题，包含参与意愿，不采集联系方式，没有隐藏的必答子题。其他项补充均选填。正式平台需验证隐藏必填、互斥、最多选项及退出路径；试填3–5人覆盖三类画像、AI未用者和Code仅试用者，以实际时间校准4–6分钟估计。

三、筛选顺序与状态

先确认本人经历与时间，再核验画像、岗位和产品使用，最后按缺口安排。未用AI、未上架或拒绝录制不影响资格；专家意见和团队转述不替代本人任务。

状态判断与处理
待核验经历、分组或意愿不清楚，先联系核实
本批入选基本条件确认，符合本批人群或场景缺口
配额候补条件符合但满额、组织集中或时间不合适
专题补充历史 / 停用经历或其他协作角色，由负责人记录纳入理由
本轮不纳入核实无本人经历，或不愿参与
已撤回停止联系，按已告知约定处理资料

导入答卷时核对矛盾项。若Q05为0但仍填了近期任务，先核实是否把正在做的首个项目漏算。若Q09选从未使用却填了Q10，或Q12选近期未用却填了Q13，先检查跳题配置，再人工核对。学生或学习者同时填有企业研发规模时，可核实是否在实习或参与企业项目。

筛选状态、场次预约和完成状态分别记录。只有完成正式访谈、观察或任务测试才计为独立参与者；问卷、预测试或预约不计入。每人统一编号，复访不重复占新增名额。

四、预约时只补本轮需要的信息

一次约5–10分钟，按用户角色选问；其他信息在正式访谈确认，不将旧长问卷整套口头重问。

必要信息简短核验
真实鸿蒙任务最近一次何时、做了什么、本人操作和结果如何？允许练习、暂停及失败案例
画像与协作组织有哪些工程平台和支持？本人项目怎样分工、工具由谁选？
项目与版本按本轮需要核实原生、迁移或跨平台方式，以及目标设备、主要技术栈、SDK / API 与工具版本
AI 实际使用在这项鸿蒙任务中用了哪些工具？用过 AI 者，按专题核实实际入口、使用环节和是否有两款工具完成同类任务的经历。未用者了解工具条件与团队使用规定
使用与熟练度选本轮目标产品，近4周大致频率？可独立完成哪两类岗位任务？用一例核验
先锋候选预约按需确认近3个月≥2个新工具 / 主要新功能、实际项目和流程调整；补一例限制与应对
意见影响力仅相关专题补问近6个月分享、指导或选型及≥2次实际使用 / 协作反馈，核验一例影响
专题条件按 Q08 核实一项本人做过的跨平台同类任务，再按需了解工程接入、开发准备或项目阶段；不要求所有人具备这些经历
参与安排确认任务形式、资料展示和录音 / 录屏。常规访谈约75分钟，资深开发者深访按需延长，最长90分钟，预约时确认。复访另约

先锋、熟练、意见影响力是可重叠标签，不是淘汰门槛。先锋争取6–8人；熟练争取10–14人（近4周每周≥1天，独立完成≥2类相关任务）；意见影响力争取3–5人。上述为本期操作定义，核验后确认；未问到记未评估，不能记不满足。Code、Studio与其他AI工具的熟练度分别记录。

五、覆盖、排期与资料

岗位约开发55%、测试 / 质量 / 发布17%、工具链 / 平台17%、技术负责人11%；AI高频、低频、近月未用各约三分之一。鸿蒙年限≤3个月、超过3至12个月、超过12个月约28%、33%、39%，预约按需补记。将Q05项目数、Q06最近任务时间与本人职责一起看，分别关注近期首个项目和有多项目经验的历史用户。熟练度用实际任务核验。流程、平台、设备缺口结合本轮任务定向补招，不要求所有交叉格都填满。

本期准备、编码、验证、签名发布各争取≥6人；暂停项目3–4人；有Android同类任务经历≥8人、有iOS同类任务经历≥6人、非手机终端≥6人，允许重叠。以上是覆盖参考，不从目的性样本推算生态分布。

两位交互各30%，合计约3人日 / 周，先安排5–8人，执行周约2场。后续形成性测试每轮5–8人，综合评估暂估10–12人，按证据与可用版本推进。每轮统计人次，本期累计去重人数；已完成首次研究者复访不扣新增名额。

公开页面只保留设计稿、规则和空白台账。真实答案、联系方式、录音和礼品登记存放在团队受控位置；正式发放前展示联系渠道、信息用途、访问范围、保留期限和撤回方式。联系方式与答案分开保存，按编号关联；停止联系已撤回者。

调整题号或标签时，同步更新研究计划、问卷、筛选规则、访谈提纲与台账。

按本轮缺口邀约，优先补齐三类团队及与研究目标相关的任务。比如选近期用 AI 做鸿蒙任务的人了解输入和验收，选用过其他 AI 工具或近期未用的人了解替代做法，再用 Q08 匹配真实同类任务做跨平台对照。对少见但相关的案例可留机动名额，记录纳入理由。联系授权由招募渠道另行确认。
