# 鸿蒙开发者访谈招募问卷

版本：2026-11-05 · 问卷设计稿

> 发布配置提示（不面向受访者）：上线前填写研究团队名称、研究联系渠道、信息访问范围、资料保留期限与撤回方式，并在开场说明中展示。当前页面只供审阅，不收集答案。

## 开场说明

我们正在规划一项鸿蒙开发体验研究，希望了解不同团队和个人在开发准备、编码、测试验证及发布中的真实做法，以及 AI 工具、工程规范与现有工具链如何参与这些工作，为 DevEco 体验优化与后续产品规划提供依据。
无论您经常使用 AI、偶尔使用或暂未使用，项目已经发布、仍在开发或曾经暂停，都欢迎分享实际经历。问卷预计需要 5–8 分钟，用于邀请适合的访谈参与者，不是考试，也不评价个人或团队的工作表现。访谈预计 60–90 分钟，具体方式和时间将另行确认。
请勿填写代码、账号、客户身份或保密项目资料；不要求上传文件。联系方式仅用于您同意的研究联系。您可停止填写，访谈中可跳过问题；录音、录屏和展示材料均需另行征得同意。

## 实际开发与工具使用

### 05. 您最近一次使用 DevEco 是什么时候？主要用过哪些产品或工具？

单选＋多选 · 必答

- 最近使用：近 1 个月；1–3 个月前；3–6 个月前；6 个月以前；从未使用
- 产品 / 工具：DevEco Studio；DevEco Code；相关命令行 / 构建调试工具；不确定名称；其他

配置说明：从未使用者隐藏产品子题。内部主样本要求近 3 个月实际使用；外部通过其他工具做鸿蒙工程者仍可进入对应专题。版本及使用频率在预约时确认。

### 06. 过去 3 个月，您亲自做得最多的鸿蒙相关工作有哪些？

多选，最多 3 项＋一句话描述 · 必答

- 需求、设计、环境或工程准备
- 编码、迁移或维护
- 构建与调试
- 测试、设备验证或性能分析
- 签名、打包、发布或上架
- 工具链 / 流水线 / Agent 接入
- 框架、三方库或服务交付
- 实际练习工程
- 近 3 个月没有相关任务

配置说明：最后一项互斥。补充一句话：最近一次实际任务大约何时、想完成什么、您做了什么、最后怎样？顺利、受阻或暂停均可，不必提供代码、截图或保密信息。近 3 个月未实践者可描述更早任务，进入补充核验。

### 08. 最近 4 周，在开发相关任务中，您使用 AI 的频率是？

### 09. 最近一次使用 AI 做开发任务时，您主要让它做了什么？

- 梳理需求 / 方案 / 验收要求

- 其他

配置说明：Q08 选择“从未”则跳过；“记不清”互斥。可选填常用 AI 工具名称。任务跟进、人工接管与结果验收留待访谈，不在招募阶段要求评价方案。
