结论

  1. 折叠发生在三层：单元、步骤组、整轮。各家看着不同，主要是选了不同的层。
  2. 主流是生成中透明、生成后收起：运行时显示「在做什么 + 计时」，结束后压成一行。
  3. 思考原文只有 DeepSeek 网页版摊开：Codex、Claude Code 的思考不进对话流，Cursor 默认收起，WorkBuddy 用计划卡代替。
  4. 收太狠会被顶回来：Codex 合并命令后宣布回滚，Cursor 整轮折叠至今被抱怨。
  5. 展开太多也会被抱怨：Claude 桌面端生成中铺开思考，挤掉答案。
  6. DeepSeek Harness 是最完整的参照：四档密度 × 两种折叠时机，都做成了设置。

L3 整轮折「这轮怎么做的」 不折；结尾一行 Worked for；全量去 Ctrl+T 不折；chat / transcript 两种视图 折叠默认完成即折成「已完成，用时」 不折；计划卡留原位，产物去右侧 折叠发下一条消息时折成 Worked for
折叠时机 —— completion（默认）/ next-input 可选 — 固定 next-input，不可关
  • 完成即折：结论刚出来，过程就被收走，用户还在对照。
  • 下一句才折：刚才几步留到用户开始下一个问题，代价是会话更长。
  • 时机比位置更容易做错：DeepSeek Harness 把两种都做成设置；Cursor 写死且不可关，是反对声最集中的一家。
