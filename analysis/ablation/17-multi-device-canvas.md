# 17 模拟器多端 · 消融记录（终轮）

- **没有 Agent**：你逐台切折叠姿态、拖本机窗口宽度，逐个点 2G / 丢包 / 断网等场景按钮，一台台看哪台坏了，再点「一多检查」、逐条接受修复。
- **有 Agent**：你说一句（「弱网下全形态过一遍」「把 lg 改成三列，别带坏手机」「一多检查并出修复」），Agent·一多 在画布上全部设备执行：场景三档依次跑、一多检查逐形态切换截图——**它验哪台哪台上台**（台前调度，台上签写「Agent·一多 在验 · …」）；过程收成一行一行的轨迹；补丁备好后停在琥珀审批卡等你「全部接受」，接受后改码（行带来源）、全部热重载、复验。原来的特征 / 手势 / 场景三条工具栏收进「手动工具」，作为接手路径。
- **多 Agent**：Mate 70 Pro 真机正被 Agent·回归 占用。名称签（台上与侧边缩略图都看得见）写明每台归谁：「· Agent·一多」「· Agent·回归 占用」；弱网会打断回归，所以 Agent·一多 不在真机上注入弱网，改用本机窗口按 sm（360 vp）代验，并在轨迹里写明；「lg 三列」只对真机截图、不装包。
