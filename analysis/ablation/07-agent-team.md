# 07 Agent Team · 消融记录（终轮）

- 没有 Agent：你自己拆任务、写页面、写逻辑、写测试，三台设备挨个装包走旅程，同一文件的冲突自己手动合。
- 有 Agent：一个 Agent 串行干完所有角色，所有等你的问题都卡在它一条长对话里，你只能一路盯着。
- 多 Agent：主 Agent 拆给 5 个子 Agent，各在隔离副本里并行；撞到同一文件、要占真机、要你选文案——所有待决进**同一个「在等你」队列**，按挡路程度排（挡住它 > 挡住开工 / 合并 > 不挡），顶栏胶囊和手机、手表实况窗都只推队首那一件。队列的样子、排序规则与 31 工作台一致。

| 元素 | 结果 | 依据 |
|---|---|---|
| 左栏「在等你」分组（3 张各带按钮的卡） | 合并 | 改成 31 同款统一队列：一行一件、编号、写明哪个 Agent · 挡住什么；点一行跳到它等你的那处。决定只在原处做一次，不在队列里再放一套按钮 |
| 状态栏 3 个胶囊（等你确认 / Team 进度 / 上架材料排队） | 合并 | 与顶栏 Agent 胶囊、队列重复；只留顶栏胶囊，推队首那件，写「还有 N 件」 |
| 在等你分组里的「已推送」小按钮 | 删除 | 「我的设备」面板本身就在，实况窗推哪件写在面板里 |
| 左栏「会话」页签与它的空态提示 | 删除 | 页签下没有内容，只有一句「会话记录在任务和团队里」 |
| 左栏「按状态分档」提示 | 删除 | 解释界面本身 |
| 看板连线图例（已交接 / 等上游 / 同改…） | 删除 | 节点状态签和红色冲突签已说明；装饰性图例 |
| 主 Agent 行的进度条 | 删除 | 与右侧「1/5」和每个节点的进度重复，留数字 |
| 「并行副本」下的说明句 | 删除 | 解释界面本身；副本卡上已写 wt/分支 |
| 5 个角色头像的彩色底（含蓝色 UI Agent） | 删除 | 角色靠图标 + 名字区分；彩色底不表达状态，蓝色不该用在身份上 |
| 主 Agent 头像的蓝紫渐变 | 删除 | 自造 AI 渐变；改 ‹✦› 智能色图标 |
| 冲突卡、交接确认卡（描边卡 / 蓝描边卡） | 合并 | 改成 ai.css 审批卡：琥珀细框 +「在等你 · …」标题；这两处就是队列里的第 1 件 |
| 在等你的任务卡、等你的看板节点（蓝框蓝底） | 保留 · 改 | 蓝 → 琥珀，只留一道细框 |
| 交接连线的流动虚线动画、设备上点按位置的扩散动画 | 删除 | 能不动的不动；交接用一颗智能色小点沿线走一次即可 |
| 节点、副本卡、旅程卡、规则条、合并条、设备舞台的描边 | 删除 | 改填充分层；选中只留一道 1px 蓝 |
| 手机壁纸的蓝色渐变、实况窗描边与阴影、接续卡蓝框 | 删除 | 蓝色大面积底；改中性填充 |
| 手机状态栏实况胶囊（蓝） | 保留 · 改 | 它表示「DevEco 等你 N 件」，改琥珀 |
| 手机 / 手表推送顺序（按任务卡在列表里的顺序） | 合并 | 改为按队列顺序，只推队首，与胶囊同源 |
| 「推送 / 接续」两行说明 | 合并 | 只留一行：实况窗推了哪件、其余几件在队列 |
| 进度条的蓝色 | 删除 | 改智能色，蓝只给主按钮 / 选中 / 链接 / 焦点 |
| Google Fonts `<link>`、300 字重 | 删除 | 字体走 tokens |
| 看板 / 规则闸门 / 并行副本 / 合并前旅程 / 我的设备 | 保留 | 本页主张：分工、交接、冲突、闸门、真机走通再合入 |
| 其他 Agent 的任务卡（调优、无障碍、上架、重构、多语言） | 保留 · 补归属 | 每张卡写明是哪个 Agent，队列里第 2、3 件就来自它们 |
| 标注 7 条 | 合并为 4 条 | 队列 → 拍板 → 闸门与合入 → 离开电脑只推队首；并新增场景卡 |
