# 06 语音开发 · 消融记录（终轮）

- 没有 Agent：放下测试机去敲键盘描述需求；工程符号被听错要手改；人一走开，构建装机没人盯，回来翻日志。
- 有 Agent：拿着测试机说一句 → 它把理解读回来并停下等你一句话（琥珀）→ 它改码、构建、装机，过程收成一行一行 → 要走开时对话接到手机、手表上继续说 → 回来接上，停在「提交」前再等你一句。
- 多 Agent：一句话里有两件事（修卡顿 + 补英文），它拆给 **Agent·调优** 和 **Agent·多语言**，派之前先复述「谁做哪件」；你说「只改 ListPage」就只派一个。手表上说「先别提交」对两个 Agent 都生效。
