# 18 分布式调试 · 消融记录（终轮）

- 没有 Agent：你在手机、手表上各装包、各开 HiLog，手动对时间戳，下断点复现，自己判断断在交接哪一步。
- 有 Agent：你说一句「流转到手表没接上，查一下」→ Agent·分布式 装包、抓两端日志、对齐时钟、复现一次（收成一行）→ 结论先行「断在第 2 步」+ 补丁 → 在等你「应用并两端复测」→ 时间轴变绿；可退回。
- 多 Agent：调试会话独占这两台，Agent·回归 要往 Mate 70 Pro 装包时进在等你队列：排到调试之后，或现在让它装（复测等它装完）。
