# 09 可视化编程 · 消融记录（终轮）

- **没有 Agent**：你拖节点、连线，再自己去代码里写 `onChange` 的处理函数、补失败 / 断网分支，画布和代码两头对。
- **有 Agent**：你只拖一条线（鼠标或 M-Pen），Agent·登录 补 `onCode()`、防重复提交和断网分支，补的节点和代码行都带来源；卡在要你拍板处停下（琥珀），在 Mate 70 Pro 上验完给结论；参数你自己调，它只重验。
- **多 Agent**：Agent·多语言 同时在把第 34 行文案换成 `$r()`，两个 Agent 撞在同一行 → 并排两版进在等你，默认「合成一版」。
