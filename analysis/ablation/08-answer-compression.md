# 08 结论先行 · 消融记录（终轮）

- 没有 Agent：自己排查、自己跑回归，结果散在 Build / Run / Profiler 里；有 AI 时回答是三段分析、结论在最后，要翻半天。
- 有 Agent：它先给一句结论 + 改动清单，过程折起来；警告和危险操作永不折叠，危险操作停下等你（琥珀）；6 分钟的长任务在后台跑，结束把一句结论推到电脑状态栏和手机锁屏实况窗，点开回 IDE。
- 多 Agent：Agent·调优（修卡顿，等你确认删 LegacyCache.ets）和 Agent·回归（跑全量回归，等你确认卸载重装）同时在等你——实况窗和顶栏胶囊只推最挡路的那一件（回归收尾），写「还有 1 件在 IDE 队列」；点实况窗回到 IDE 直接落在那一件上。
