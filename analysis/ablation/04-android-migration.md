# 04 安卓转化 · 消融记录（终轮：Agent 化）

- 没有 Agent：两台手机摆桌上（或打开并排对照后）你自己在两版里各点一遍、肉眼找不同，再翻代码找行、一处处点「按原版改」，安卓新提交再一条条手动同步。
- 有 Agent：点「对照两版」，Agent·转化 在同一台鸿蒙电脑上用卓易通跑安卓原版、本机窗口跑鸿蒙版，按记录的 4 步同步回放，找出 4 处差异，能按原版改的直接改（错误码改 Toast、商品图圆角）并热重载重放验证，过程收成一行行工具调用；需人工的和撞车的停下来进「在等你」队列。你自己点两版的并排对照、标记已查、让 Agent 解释差异、同步安卓提交保留为次路径。
- 多 Agent：下拉刷新要改 ListPage.ets 的 List，Agent·列表 正在同一个 List 上改 cachedCount——按意图分组后合成一次改动，作为「挡住它」的一件排在队首；「短信自动填充没有对应 Kit」作为「需人工」排第二，顶栏胶囊只推第一件，写「还有 1 件」。
