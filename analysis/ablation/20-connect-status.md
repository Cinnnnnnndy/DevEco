# 20 连接状态 · 消融记录（终轮）

- 没有 Agent：连接卡住，你看五步卡在哪步，再自己搜报错、重插线、`hdc list targets`、`hdc kill -r` 重启——重启时不知道会断掉谁的会话。
- 有 Agent：点「交给 Agent」→ Agent·连接 诊断（收成一行：`hdc list targets` Offline → 重新枚举 → 换端口 → 查到 8710 上是旧版 hdc server 3.1.0）→ 结论先行「卡在第 3 步」→ 能修的（不打断别人的）它先自己试，要重启 hdc 才停下问你 → 你选「等它抓完再重启」→ 它等、通知、重启、连回，五步走完。
- 多 Agent：重启 hdc 会断开这台电脑上所有 hdc 会话。审批卡先列出受影响的 Agent（Agent·回归 在模拟器上跑 UI 回归 34/120、Agent·性能 在 Pura 70 Pro 上抓 trace 还剩 40 秒）和不受影响的设备，再问你「等它抓完」还是「现在重启」；设备表「状态」列标出每台正被哪个 Agent 用。

| 元素 | 结果 | 依据 |
