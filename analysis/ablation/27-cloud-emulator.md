# 27 云端模拟器 · 消融记录

- 没有 Agent：自己在 Device Manager 里云端多开 → 选旅程、勾形态 → 并行跑 → 挨个点红格看现场 → 点「交给 AI 修」→ 只重跑那台 → 看侧边红点发现带坏了别的台 → 再修 → 提交。
- 有 Agent：在 DevEco Code 里说一句「checkout 全形态过一遍，坏的修好，提交前问我」→ Agent·回归 按 module.json5 挑 6 种形态（手表未声明 wearable 跳过）、在云端测试池起实例跑旅程 → 自己修 2 处失败格、只重跑那两台 → 看到平板和三屏被第一版修复带坏，自己细化 → 停在提交前等你（琥珀）→ 你批准后整轮复跑、结果写回提交。手动多开 / 迁移 / 手动跑退为 Cloud Emulators 页签与「并行跑 6 台」次路径。
- 多 Agent：云端测试池每个 Agent 各一套——Agent·多语言 在华南另占 4 台、Pura 70 Pro 交互实例被它租着（设备角标写「Agent·多语言 在用」），互不抢；它的 RTL 截图待看排进胶囊「还有 1 件」，不挡这条任务。
