# 25 手机客户端 · 消融记录（终轮）

- **没有 Agent**：不在工位时只能记下「登录点了没反应」，回到电脑插线、装包、复现、翻 HiLog、找到行、改完再装回手机点一遍。
- **有 Agent**：在手机上的 DevEco Code 里说一句，Agent 在这台手机上装包、自动复现、抓 HiLog、定位到 `LoginPage.ets:27`、写补丁，每步一行收在对话里；补丁停下等你（琥珀审批卡：应用到这台手机？/ 碰一碰回电脑细看）；批了就重装、用同一组点击复测，给前后对比。顶栏胶囊一路写它在做什么。
- **多 Agent**：同时 Agent·多语言 在电脑上跑，也有一件要你批（给登录页补维吾尔语文案）。手机只推最挡路的一件：补丁在前，多语言那件在审批卡下写「还有 1 件 · 不挡路，排在后面」；补丁做完它才轮到，可以在手机上批，也可以留到回电脑再看。
