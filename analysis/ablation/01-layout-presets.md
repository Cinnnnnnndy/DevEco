# 01 布局预设 · 消融记录（终轮：Agent 化）

- 没有 Agent：你按任务手动切「调试 / 审阅 / 多设备验证」，每次自己开合面板、拖应用窗口、手机镜像和 Profiler。
- 有 Agent：你说一句「ListPage 滑动掉帧，改好后在 Mate 70 Pro 上验」，布局跟着 Agent 的阶段自己切——干活时「盯它干活」（DevEco Code + 应用窗口），停下等你时「审阅」（审批卡置顶 + Commit），上设备时「多设备验证」（应用 + 手机镜像 + Profiler）；你只定每套长什么样，手动切预设 / 「调试」退为接手时的次路径。
- 多 Agent：Agent·多语言 同时在等你但不挡路——布局不跟着它抖，只在胶囊写「还有 1 件」，点胶囊才切过去拍板。
