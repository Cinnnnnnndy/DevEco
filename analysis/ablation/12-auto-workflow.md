# 12 自动化 Workflow · 消融记录（终轮）

- **没有 Agent**：每次手动敲一串（打测试包 → 测试签名 → 上传 AGC → 通知测试组），被催包就得回工位开 IDE 盯着传完。
- **有 Agent**（本页本来就是 Agent 形式，这轮只做统一）：它看出你重复就提议存成一句命令；之后你在 IDE、电脑小艺或手机上说一句，它在后台跑整串，只在「发给 18 个人」之前停下等你（琥珀）；进度就在顶栏 Agent 胶囊里，点开是实况窗卡片，手机锁屏同步。
- **多 Agent**：第一次运行时 Agent·回归 正在用 hvigor 编 entry，同一个 `build/` 不能两边同时写 → /test-pack 先排队（胶囊、步骤、实况窗、手机上都写「排队 · 等 Agent·回归 编完」），轮到再跑；停下等你时胶囊写「还有 1 件」，实况窗卡片底部列出另一件（Agent·回归 用例失败要不要重跑，不挡这次发包）。
