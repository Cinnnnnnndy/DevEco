# 24 插件化开放 · 消融记录（终轮）

- **没有 Agent**：开发者自己挨个开插件：设备下拉里选机、Profiler 页签里录 Frame、另开网络抓包、在日志过滤器里筛 Tag 和 Level，再自己把几处的时间对上。
- **有 Agent**：插件装上，它挂的扩展点同时注册成 Agent 能调的工具（profiler.record、hilog.query、netcap.capture…）。你说一句「ListPage 滑动掉帧，查一下是不是网络拖的」交给 Agent·调优：它调 Profiler 录 Frame、调 HiLog 筛日志；要用还没启用的三方插件「网络抓包」时停下等你（琥珀，写明插件来源、挂在哪、读什么）；结果落回原生位置——Profiler › Frame、Profiler › 网络抓包、日志过滤器——各自标「Agent·调优 录制 / 抓包 / 设的过滤」；结论先行给出「不是网络拖的，改 ListPage.ets:28」。手动启用、切宿主、拆自由窗口保留为次路径。
- **多 Agent**：Agent·回归 同时也要 `profiler.record` 录冷启动；同一采集会话一次只给一个 Agent（不然帧率互相污染），它排在 Agent·调优 后面，写明原因，轮到后自动开始。
