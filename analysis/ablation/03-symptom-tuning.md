# 03 症状调优 · 消融记录（终轮：Agent 化）

- 没有 Agent：你插线让测试再滑几遍等复现，自己挑指标（帧耗时 / 堆内存…）、翻火焰图找热点、改代码，再手动录一条对比，跑一次像好了就算。
- 有 Agent：你只说「列表滑起来卡」（或拿同事手机碰一下），Agent·调优 读 trace、定位到 ListPage.ets:28、出两处补丁，过程收成两行工具调用；停在「2 个补丁待审」等你（顶栏胶囊琥珀，点它跳到补丁）；你接受后它在同一台手机上用同一手势复测，可让它各跑 5 次判显著。点柱子定位、最重调用栈、记录列表保留为你接手查证的次路径。
- 多 Agent：复测要独占这台 Mate 70 Pro（别的负载会污染帧率）——设备条写「调优在复测，勿动」，Agent·回归 的装包排在后面，复测完自动释放给它。
