# 16 多设备验证 · 消融记录（终轮）

- **没有 Agent**：逐台插线装包、拉起、走到 ListPage、截图，对着一多断点规则一张张判「适配还是缺陷」，再自己去改代码、再挨台重跑。
- **有 Agent**：你说一句「在桌上几台上验一下搜索框这次改动」；Agent·验证 读改动、发现两台没连就停下等你碰一下（琥珀），接着 3 台并行跑，逐处对照判法规则预判——判到哪处哪台上台；适配的收成一行，缺陷的带补丁停下等你确认；你确认后它改码（行带来源）、热重载、只重跑那一台。
- **多 Agent**：Mate X6 真机正被 Agent·回归 占用（12/38）。Agent·验证 不抢：先开本机窗口按 md（2440×2240 等比）跑，结果标明来自本机窗口；回归用完后自动在真机上复核 md，一致才收尾。设备卡、验证列表写明谁占着、还要多久。
