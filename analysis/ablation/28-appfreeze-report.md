# 28 冻屏分析报告 · 消融记录（终轮）

- **没有 Agent**：拿到 faultlog 自己读 EventHandler 队列、主线程栈、线程列表，按排除法走一遍，再翻源码和 git 找到行、手写补丁，最后在真机上开冻屏测试模式连点复现、看有没有再上报。
- **有 Agent**：报告本身由 Agent·冻屏 生成（写明读了 faultlog、HiLog、源码 4ca0c7e），结论先行；结论每一行标「证据」或「推断」，悬停看依据。源码可达版点「让 Agent 修并真机复测」→ 它写入 3 处补丁（修复卡标「Agent·冻屏 写入 · 退回」）、构建 → 停下等你（琥珀：覆盖安装、打开冻屏测试模式、连点 3 轮）→ 在 Mate 70 Pro 上复测 → 结论回填「已修复 · 复测 3/3」，证据清单多一项「真机复测」。源码不可达版点「让 Agent 读源码出补丁」→ 先问你要读源码的许可 → 检索 + git 考古后切到源码可达版，推断变成证据。
- **多 Agent**：证据按任务 / Agent 归档：「采样栈」缺数据时，报告写明同一时段有一份 Agent·性能 的 trace（任务「ListPage 掉帧」），归那个任务、不混进来；点「引用到本任务」后这一项变为命中并标「引自 Agent·性能」，原始 trace 仍留在原任务。
