# 13 设计稿到代码 · 可视化修改 · 消融记录（终轮）

- **没有 Agent**：对着设计走查意见，在 Previewer / 模拟器上逐个点元素、拖间距、改属性，拖出来的是 `.padding(13)` 这种裸值；改完自己开折叠屏、平板挨个看，Ctrl+Z 会把自己和 AI 的改动一起撤，设计稿越改越旧。
- **有 Agent**：你只拖、圈、说一句。拖（只改值、零延迟、不经过 Agent）松手后，它把值翻成 token 并问「改到哪 × 哪些断点」，每项写影响几处，连续第 3 次同类修改时默认值改成「ProductCard 本身」并说明理由；结构性改动先用虚线框确认范围再出 diff（琥珀「在等你」）；写回后 sm / md / lg 三档自己跑，问题档琥珀、点开就换到那台设备；每处改动记一条来源（你不打标 / Agent `.ai-src` / 设计稿同步中性小字），勾掉只退那一条；设计稿漂移逐条写明谁改的、三选一。
- **多 Agent**：你一动它就停——Agent·界面 生成中你去拖卡片，它先停下，松手后在你的值上继续，同一属性听你的；Agent·多语言 同时改过 ProductCard 的「已售」文案，它的改动也记在改动记录里，和这次 diff 不同行、按行合并，也能单独退。

没做的一处：**「全局 token」作用范围档**。它和第一行「写成哪个 token」语义重叠（改 token 的取值是设计系统的决定，不该由拖一下卡片触发），合进来要多一行条件 UI；按「简洁优先」只留「只这一页 / 组件本身」两档，改 token 值留给设计系统侧。
