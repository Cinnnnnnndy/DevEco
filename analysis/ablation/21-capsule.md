# 21 智慧胶囊 · 消融记录（终轮）

- 没有 Agent：没有「它在等你」这回事——长任务自己盯进度条，离开电脑就断了。
- 有 Agent：你交代完就去开会；Agent·列表 停在「要不要改 ListPage.ets、ItemCard.ets」等你拍板。顶栏胶囊亮琥珀，升到实况窗后电脑右上角、Mate 70 Pro 锁屏、WATCH 5 同步；锁屏直接批准 → 它改码、构建、装机（胶囊跟着走 1/4…4/4）→ 装好后在手机上验收 120 fps。
- 多 Agent：Agent·上架 在排队生成上架材料。胶囊只推最挡路的一件（Agent·列表 的审批），另一件生成好后进同一个「在等你」队列、标「不挡路」，胶囊写「还有 1 件」；手机锁屏只放最挡路的一张卡，其余收成「还有 1 件」一行。

| 元素 | 结果 | 依据 |
|---|---|---|
| 编辑区上方自造的两枚浮动胶囊（渐变底、呼吸光、描边 + 双层阴影、宽度变形动画） | 删除，合并 | 与 frame 顶栏统一的 Agent 胶囊重复；两枚并排等于「各弹各的」。改为一枚胶囊只推最挡路的 + 点开是统一「在等你」队列（ai.css 审批卡 / 工具行） |
| 准入卡标题下「胶囊四条之外，再加一条…」与五枚准入条件胶囊 | 删除 | 解释规则本身，不帮开会时拍板这一步；规则体现在每行推到哪台（电脑 / 手机 / 手表） |
| 设备台面点阵底纹 | 删除 | 纯装饰 |
| 设备点亮时的蓝色外扩光圈 | 删除 | 外发光；手机 / 手表保留震动（它就是提醒本身） |
| 电脑 / 手机壁纸的蓝绿渐变、桌面图标里的蓝绿色块、手机应用缩略图渐变 | 改为中性填充 | 大面积蓝与渐变；只留状态色 |
| 实况窗卡片的描边 + 阴影 + 毛玻璃、回弹入场 | 合并为一层阴影、只减速入场 | 描边叠加、回弹动效 |
| 「升到系统实况窗」开关与设备签的蓝色选中 | 改为中性反色 | 开关用中性，不用蓝（ai.css 规则） |
| 「在等你」的蓝点（电脑胶囊、手机胶囊、手表圆环） | 改为琥珀 | 在等你只用琥珀，是唯一抢注意力的态 |
| Google Fonts、700 / 300 字重 | 删除 | 字体走 tokens，字重 400–600 |
| 引导标注第 1 条压住胶囊弹层标题 | 改位置 | 标签放到胶囊左侧，不压队列 |
