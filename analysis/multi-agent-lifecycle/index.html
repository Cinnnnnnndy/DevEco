01 / 先回答核心问题

主 agent 的一轮输出结束、一个子 agent 停止、整段对话完成，是三件不同的事。界面应分别表达执行者状态和任务整体状态。

DevEco 建议

主 agent 已停止，仍有 2 个子 agent 执行：显示「子任务运行中 · 2」，副文案「主 agent 已停止」，保留「查看子任务」与「停止全部」。不能显示整段对话已停止。

研究日期：2026-10-22。七产品官方文档研究版，未登录逐端执行；文档确认不等于实机验证。未取得可证明默认值和停止转换的真实截图，下面示意图均为设计建议。

03 / 展示层级与默认折叠（DevEco 建议）

L1 主对话

保留用户目标、主 agent 汇总、待决策事项、最终产物。委派显示为任务组摘要，附运行 / 等待 / 失败数量。

L2 子任务卡

默认压缩正文，常显名称、任务摘要、当前动作、状态、耗时与停止入口。完成显示结果一句话，保留来源入口。

L3 子任务详情

按需展开任务提示、执行时间线、工具输入输出、修改文件、验证和结果。可在侧面板打开，保留父任务返回路径。

运行中的当前动作保持可见；成功详情默认收起；错误摘要与待授权动作常显。用户手动展开后不因状态变化强制收起。结果不能被折叠进不可发现的过程日志。

不要把模型内部推理当成必须展示的正文；展示可用的执行摘要与工具证据。

04 / 停止作用域（DevEco 建议）

操作作用域回执与后续
停止全部（对话主入口）当前任务轮次主 agent + 所有活跃后代 + 待启动委派先显示停止中；拒绝继续派生，等待逐项回执。超时显示仍运行的对象，允许重试。
停止此子任务（卡片）该子任务及其活跃后代同级任务继续；主 agent 得知取消，可汇总部分结果；不得无提示自动重启被取消任务。
仅停止主 agent（次级入口）主 agent 当前轮次明确标注子任务继续；整段对话显示剩余子任务状态。

是否需要单独停止子 agent？建议提供：用户可以取消走偏或无价值的分支，而保留其他成果。同时全局停止必须能一次结束整个任务，不能要求用户逐个清理。

停止不等于撤销：已完成修改保留供审阅。工具进程、远程作业是否已终止须单独确认；无法确认时显示「停止未确认」，不能先宣告全部停止。

05 / 对话状态矩阵（DevEco 建议）

不要直接复制主 agent 的状态。聚合需要主 agent、后代任务、工具作业、取消回执和结果汇总状态共同参与。待授权作为注意事项优先展示，同时保留仍运行数量。

主 agent子任务 / 条件对话显示辅助信息
执行中任意运行中主 agent 当前动作；子任务运行数量
已停止 / 本轮结束至少一个运行子任务运行中 · N主 agent 已停止 / 本轮结束；查看与停止全部
等待子任务存在运行等待子任务 · N主 agent 无输出不等于停止
任意需要用户授权待处理 · N指明请求来自哪个子任务；其他运行数量并列
取消已发出仍有未确认停止中 · N保留未确认对象；超时可重试
已停止全部取消确认已停止保留部分结果与文件修改
已结束子任务已结束，尚未汇总待汇总结果已就绪；允许主 agent 继续汇总
汇总完成全部成功或已处理已完成展示验收结果与产物
已结束失败且目标未达成部分完成 / 失败失败范围、已有成果和恢复入口

idle / 可恢复只代表没有当前执行，不计入运行数量；断线状态标为未知并重新同步。旧轮次完成回执不能覆盖新轮次状态，按 taskId、agentId、runId 和递增事件版本归属。

07 / 实测与验收清单

统一任务：主 agent 同时派生“代码检索”和“长耗时验证”两项工作，验证任务再派生一个后代。分别执行：主 agent 自然结束、点击全局停止、单停一个子任务、等待授权时停止、断线重连后停止。

每个客户端记录版本、配置、原始默认值、截图与录屏。观察停止前、点击后、回执后、重连后四个时点。必须检查真实工具进程与远程作业，不能只看转圈是否消失。

  • 主停子未停时不会显示整段已停止。
  • 子任务可定位到父任务、提示、过程与结果。
  • 折叠不隐藏当前动作、失败和授权入口。
  • 全局停止覆盖全部活跃后代，取消中仍可发现剩余对象。
  • 部分失败不抹掉其他分支成果；迟到结果不会自动重启已取消任务。
  • 键盘可展开详情，状态变化有文本说明，颜色不是唯一标识。
