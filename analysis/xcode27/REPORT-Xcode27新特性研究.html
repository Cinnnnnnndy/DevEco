Device Hub：真机和模拟器合到一处，给人用，也给脚本和 Agent 用

随 Xcode 27 一起装、取代 Simulator.app 的独立 App。Apple 自己的一句话概括是「模拟器的方便，加上真机的保真」。这是全报告最细的一页。

二 · 为什么苹果现在做它四层动因

先看 Apple 自己怎么讲动机，再看技术、平台和同行。能落到原话或文档的标「官方」，我们的判断标「推断」。

a场景与问题：设备多、组合多、两套工具

  • 组合爆炸：要在「every device, at every appearance, at every text size」都好看，「that can be a lot to account for」260 · 0:13 官方
  • 真机和模拟器分工明确，却分在两处：真机测性能、传感器、真实环境，模拟器补旧系统和手头没有的机型——「Xcode 27 brings both together」SOTU 47:36 官方。此前模拟器在 Simulator.app 里一台一个窗口，真机在 Xcode 的设备窗口里管 推断
  • 设备多到管不过来、改配置费时：「I work with dozens of devices and simulators」4:40；「testing different text sizes, simulating different locations, or installing different profiles - that can still take a lot of time」5:53 官方
  • 真机上出的 bug 换个人、换台模拟器就复现不出来：session 花了 7 分钟演示「真机发现 → 模拟器复现」8:08 官方

b技术发展：Agent 要自己验，底层已经统一

  • Agent 写完代码要能自己看、自己点：「Agents can now boot simulators, install and launch apps, synthesize touch events, and capture screenshots to verify UI behavior」，还能转表冠、按侧键（watchOS）、用 Siri Remote 导航（tvOS）——Xcode 27 release notes 官方。SOTU 现场演示 Agent 在 Device Hub 里点、滑、打字，最后给测试小结和一路的截图 53:37 官方。设备层因此必须可编程、可截图、能同时服务人和 Agent 推断
  • CoreDevice 一套底层：devicectl 与 Device Hub 同源 15:55 官方；devicectl 开始能操作模拟器，但文件拷贝、描述文件、sysdiagnose 等在 27.1 beta 上对模拟器还会报错，CI 仍以 simctl 为主 社区 · 搜索摘要
  • 「We rebuilt the experience from the ground up for the highest fidelity possible」SOTU 48:22：Mac 的滚动、捏合、旋转手势在 iOS 设备上产生标准 UIKit 事件（release notes 48372360）官方

c平台与硬件：iPhone 应用可以变大小，形态越来越多

  • iOS 27 里 iPhone 应用在 iPad 上、在 macOS 27 的 iPhone 镜像里「will be fully resizable」278 · 6:50；所以要有不装多台模拟器也能试各种尺寸的方式——Device Hub 与 Previews 的「enter resize mode」8:44 官方
  • 形态越来越多：Watch、TV、Vision Pro（模拟场景、FaceTime / SharePlay）、CarPlay（27.2 起经 USB）、iPhone Duo（27.1 新增模拟器运行时，预览多了「另一块显示屏」分组）官方；iPhone Duo 模拟器 9 月 18 日随 27.1 beta 出现，10 月 23 日发售 媒体 · 搜索摘要
  • 系统层的新连接：iOS / iPadOS / watchOS 27 支持网络配对，「without requiring a cable, and provides a more reliable experience for pairing watches」（release notes 179418483）官方

d竞争与生态：同行早有，第三方先补，AI 工具都在驱动模拟器

  • Android Studio 早把模拟器嵌进 IDE 的 Running Devices 工具窗，真机画面也能镜像进来直接操作 社区 · Android 官方文档，搜索摘要；Xcode 这次在「IDE 里直接操控设备」上补课 推断
  • 第三方工具先补了位：RocketSim（截图录屏、网络、Agent 控制）、ControlRoom（改外观、状态栏、位置）；RocketSim 已改为在 Device Hub 之上加功能 社区 · 厂商文案。高频需求被收进官方 推断
  • AI 编码工具都在驱动模拟器：Simulator.app 换成 DeviceHub.app 后，Claude Code 桌面版、Expo、React Native CLI、sweetpad 等都开 issue 适配 社区 · GitHub——设备层已是 Agent 时代的基础设施，Apple 把它收成官方的一层 推断

三 · 场景Apple 演示的五个任务流

S1 · 写完就跑，顺手把外观查一遍

What's new in Xcode 27 9:54–12:31 · 设计师 Jake 在做纸飞机 App
  1. 运行到 iPhone 17 Pro 模拟器 → Device Hub 弹出紧凑窗，「compact and sized to fit the device」
  2. 紧凑窗里直接回主屏、截图、旋转
  3. 展开窗口、打开检查器：增强对比、调大动态字体、切深色，看完恢复默认
  4. 进尺寸调整模式试不同宽高比——因为 macOS 27 的 iPhone 镜像窗口可以拉大小
  5. 打开侧栏：模拟器和真机在一张列表里；已配对的 iPad Pro 正在跑这个 App，在 Device Hub 里直接看、直接操作

Release notes 里的已知问题（摘要）

  • Device Hub 27 不能显示物理 Apple Vision Pro 的画面、也不能向它发输入，其他功能（设置、DeviceFS 等）可用，画面可用 AirPlay 代替 官方
  • 暂不支持向设备或模拟器发送双指触摸；Controls › Shake 不工作 官方
  • 并行测试时，模拟器在 Device Hub 里看不到但仍在跑测试；想看 UI 测试执行要关掉并行 官方
  • 下载的数据容器是以 bundle ID 命名的文件夹，不是 .xcappdata，要手动改结构才能给 Xcode 的 Run 动作用 官方
  • CarPlay 需 USB 连接，不支持 iOS 模拟器；iPhone Duo 上 VoiceOver 与辅助功能检查器还读不到 Device Hub 里的屏幕内容（27.2 beta 2） 官方

八 · 鸿蒙电脑版可以参照什么

先看一个差别：Device Hub 把设备分成「模拟器 / 真机」两类。鸿蒙电脑版「开发环境即运行环境」，PC 应用本机就能跑，所以至少是三类——本机窗口 · 模拟器 · 真机（真机再分 USB、无线、碰一碰、远端、云端）。照搬两分法会漏掉我们最大的优势 推断。

已经借过的：demo 20 的「设备中心」已按 Xcode 27 补了五类设备一张表、一键诊断包、在云端 / 远端真机回放复现（见 README「对照友商更新」）。还没借的：活屏画布、紧凑窗、情境化控件、检查器里即时生效的环境设置、数据与配置一起搬的复现、一个设备层同时给界面 / 命令行 / Agent 用。
