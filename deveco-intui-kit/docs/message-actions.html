DevEco Code 对话面板里，每条消息下面那一排：两个图标，一个时间。这一页写清它在每种消息、每个状态下显示什么。样张都是真组件，能悬停、能点。

什么时候有消息完成之后才有；生成中、在等你都没有。报错或中断时，换成带文字的「重新回答」加复制。
有什么AI 回答：复制 · 重新回答 · 时间。你发的：时间 · 编辑 · 复制。没有有用 / 没用，没有朗读，没有更多。
怎么摆AI 回答靠左、常显；你发的靠右、悬停才现。时间长度不定，两边都放在里侧，图标位置不动。

概览

01

叫什么、用在哪、每个动作做什么。

叫什么

消息操作栏（Message Action Bar），别处也叫 hover actions、message toolbar。

Int UI 里对应 ActionToolbar + ActionButton + 次要文本；实现是 src/ai.css 的 .ai-msgbar。

用在哪

对话面板里每一条已完成的消息。作用对象永远是这一条，不是整段对话，也不是其中一块代码。

  • 不用于代码块：代码块的复制 / 插入挂在代码块右上角。
  • 不用于审批卡：允许 / 不允许是「在等你」，有琥珀。
  • 不放对话级操作：新建、历史、导出、反馈都在面板头。

每个动作做什么按栏里的顺序

动作做什么反馈在哪种消息
复制复制整条消息的原文（Markdown）。图标变绿勾，1.5 s 复原AI 回答 · 你发的
重新回答用同样的输入再生成一条，旧的留在上面。报错或中断时带文字。新回答出现在下面AI 回答
编辑改你发的那条，从这条起重新生成；下面旧的回答折叠起来，不删。气泡变成输入框你发的
20 分钟前这条完成的时刻。相对时间，悬停看绝对时间；规则见第 06 章。—AI 回答 · 你发的

变体

03

两种消息。按钮和对齐方向不同，尺寸和颜色一样。窄面板不折叠：两个图标加时间约 120 px。

AI 回答

复制 · 重新回答 · 时间，靠左，常显。回答本身不套卡片，直接排在面板底上。

你发的消息

时间 · 编辑 · 复制，靠右，悬停才现。平时这一行只占位，出现时高度不变。改过的在时间后加「已编辑」。

时间戳

06

时间是这条完成的时刻。显示相对时间，悬停看绝对时间；每 60 s 刷新一次，只刷看得见的。

显示规则

距现在显示悬停
< 1 分钟刚刚2026-10-08 14:32:05
< 60 分钟20 分钟前2026-10-08 14:12:33
今天09:412026-10-08 09:41:07
昨天昨天 18:052026-10-07 18:05:40
今年10 月 1 日 14:122026-10-01 14:12:00
更早2025-12-30 14:122025-12-30 14:12:00
  • 报错 / 中断：前面加状态，「失败 · 3 分钟前」「已停止 · 刚刚」。
  • 改过的消息：后面加「· 已编辑」，悬停看发送和编辑时间。
  • 不写秒、不写「大约」、不写「N 小时前」：超过一小时直接给时刻。
